# 🏊‍♂️ JJ Swim Lab

**AI 기반 수영 교육 플랫폼** - 개인 맞춤형 수영 강습법, 퀴즈, 진도 관리, 그리고 **3D 수영 자세 분석** 기능을 제공합니다.

## ✨ **주요 기능**

### 🎯 **3D 수영 자세 분석** ⭐ **NEW!**
- **인터랙티브 3D 뷰어**: 마우스로 회전, 확대/축소 가능
- **4가지 수영법 지원**: 자유형, 평영, 배영, 접영
- **자세 분석 시스템**: AI 기반 자세 평가 및 점수 제공
- **측정 도구**: 정확한 각도 및 거리 측정
- **학습 가이드**: 수영법별 핵심 포인트와 실전 팁

### 🤖 **AI 기반 수영 교육**
- 개인 수준과 목표에 맞는 맞춤형 강습법 추천
- 실시간 자세 분석 및 피드백
- 진도 추적 및 개선점 제안

### 🧩 **인터랙티브 퀴즈**
- 수영 이론과 실기를 재미있게 학습
- 난이도별 퀴즈 제공
- 학습 효과 증대

### 📊 **체계적 진도 관리**
- 개인의 수영 실력 향상 추적
- 목표 설정 및 달성도 모니터링
- 개인 맞춤 학습 계획 수립

### 💬 **커뮤니티 시스템**
- 수영 애호가들과 정보 공유
- 경험담 및 팁 교환
- 전문가 Q&A

## 🚀 **빠른 시작**

### **필수 요구사항**
- **Node.js**: 18.x 이상 (권장: 22.17.0)
- **pnpm**: 8.x 이상 (권장: 10.12.4)
- **Git**: 최신 버전

### **설치 및 실행**
```bash
# 저장소 클론
git clone <repository-url>
cd jj-swim-lab

# 의존성 설치
pnpm install

# 개발 서버 실행
pnpm run dev

# 빌드
pnpm run build
```

### **포트 설정**
- **클라이언트**: 3000번 포트
- **서버**: 5000번 포트

## 🏗️ **기술 스택**

### **프론트엔드**
- **Next.js 14.2.5**: App Router 기반
- **React 18.3.1**: 최신 React 기능 활용
- **TypeScript 5.x**: 타입 안전성 보장
- **Tailwind CSS 3.3.0**: 유틸리티 기반 스타일링
- **Three.js**: 3D 그래픽 엔진
- **@react-three/fiber**: React용 Three.js 래퍼
- **@react-three/drei**: Three.js 유틸리티

### **백엔드**
- **Node.js**: 서버 런타임
- **Express.js 4.18.2**: 웹 프레임워크
- **MongoDB Atlas**: 클라우드 데이터베이스
- **Mongoose**: ODM (Object Document Mapper)

### **패키지 관리**
- **pnpm**: 모노레포 구조 지원
- **모노레포**: client와 server 패키지 분리

## 🎯 **3D 기능 사용법**

### **접근 방법**
1. **직접 URL**: `http://localhost:3000/3d-swimming`
2. **메인 페이지**: 3D 수영 자세 분석 카드 클릭
3. **네비게이션**: 🎯 3D 자세 분석 메뉴

### **3D 뷰어 조작법**
- **마우스 드래그**: 3D 모델 회전
- **마우스 휠**: 확대/축소
- **수영법 선택**: 자유형, 평영, 배영, 접영 중 선택
- **자세 분석**: "자세 분석 시작" 버튼으로 분석 실행
- **측정 도구**: "측정 도구 활성화" 버튼으로 측정 시작

## ⚠️ **현재 알려진 이슈**

### **네비게이션 메뉴 표시 문제** 🚨
- **현상**: 데스크탑에서 3D 페이지, 지도, 상점 등 메뉴 항목들이 표시되지 않음
- **원인**: CSS 스타일링 또는 조건부 렌더링 문제로 추정
- **상태**: 메뉴 데이터는 정상 로드되나 UI 표시에 문제
- **해결 계획**: 데스크탑 환경에서 추가 디버깅 및 수정 작업 필요

### **임시 해결책**
- **직접 URL 접근**: `/3d-swimming` 등 직접 입력으로 페이지 접근 가능
- **기능은 정상**: 3D 페이지 자체는 완벽하게 작동

## 🔍 **문제 해결**

### **일반적인 문제들**
- **포트 충돌**: `netstat -ano | findstr :3000`으로 확인
- **TypeScript 오류**: `pnpm run type-check`로 타입 검사
- **의존성 문제**: `rm -rf node_modules && pnpm install`로 재설치

### **3D 기능 문제 진단**
- **WebGL 지원 확인**: 브라우저 WebGL 지원 여부 확인
- **Three.js 에러**: 브라우저 콘솔에서 Three.js 관련 에러 확인
- **모델 로딩**: 3D 모델 파일 경로 및 형식 확인
