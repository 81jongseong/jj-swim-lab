🧠 퀴즈 관리 시스템 완전 개선

✨ 주요 개선사항:
• 테이블 → 카드 UI 변환 (가로 스크롤 완전 제거)
• 완전 반응형 디자인 (모바일/태블릿/데스크톱)
• 페이지네이션 구현 (10개씩 깔끔한 분할)
• 편집/삭제 기능 완전 구현

🔧 기능 구현:
• 퀴즈 생성: 커스텀 카테고리 + 다양한 문제 유형
• 퀴즈 편집: 완전한 편집 모달 + 실시간 수정
• 퀴즈 삭제: 안전한 삭제 + 권한 확인
• 상세보기: 모든 정보 표시 + 편집 연결

📊 데이터 구조 개선:
• 객관식 + 단답형 문제 지원
• 커스텀 카테고리 무제한 추가
• 스마트 자동 채점 시스템
• 서술형 제거로 관리 간소화

🐛 해결된 오류:
• API 경로 404 오류 → 포트 통일
• PUT/DELETE 500 오류 → 권한 로직 개선  
• 가로 스크롤 문제 → 카드 UI 변환
• 옛날 데이터 스키마 불일치 → MongoDB 직접 정리

🎨 UI/UX 개선:
• 아름다운 카드 디자인 (그라데이션 아이콘, 그림자 효과)

• 색상 코딩 (난이도별 색상 구분)
