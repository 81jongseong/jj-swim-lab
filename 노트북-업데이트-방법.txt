========================================
노트북에서 프로젝트 업데이트 방법
========================================

update-project.bat 파일이 없는 경우
다음 명령어를 직접 실행하세요.

========================================
방법 1: Cursor 터미널에서
========================================

1. Cursor에서 프로젝트 열기
2. 터미널 열기 (Ctrl + ~)

3. 다음 명령어 순서대로 실행:

cd C:\Users\JJS\jj-swim-lab

git fetch origin

git checkout glb-debug-viewer

git pull origin glb-debug-viewer

git log --oneline -1

========================================
방법 2: 명령 프롬프트(CMD)에서
========================================

1. Windows 검색에서 "cmd" 입력
2. 명령 프롬프트 실행

3. 다음 명령어 순서대로 실행:

cd C:\Users\JJS\jj-swim-lab

git fetch origin

git checkout glb-debug-viewer

git pull origin glb-debug-viewer

git log --oneline -1

========================================
방법 3: Cursor UI에서
========================================

1. Cursor에서 프로젝트 열기
2. 좌측 하단의 소스 제어 아이콘 클릭 (분기 아이콘)
3. "Pull" 또는 "Fetch" 버튼 클릭

또는

1. Ctrl + Shift + P (명령 팔레트)
2. "Git: Pull" 입력 후 선택

========================================
업데이트 확인
========================================

다음 명령어로 최신 커밋 확인:

git log --oneline -1

예상 결과: c68bc3b (또는 그 이후)
