# 🔍 JJ Swim Lab - 검증 스크립트

이 디렉토리는 프로젝트의 모든 검증 작업을 자동화하는 스크립트들을 포함합니다.

## 📋 사용 가능한 스크립트

### 🚀 통합 검증 (모든 검증 실행)

```bash
# 모든 검증을 한번에 실행
npm run check
# 또는
npm run check:all
# 또는
npm run validate
```

**실행되는 검증 항목:**
- ✅ 서버 빌드
- ✅ 클라이언트 빌드  
- ✅ 서버 테스트
- ✅ 클라이언트 테스트
- ✅ 서버 린팅
- ✅ 클라이언트 린팅
- ✅ 서버 타입 체크
- ✅ 클라이언트 타입 체크
- ✅ YAML 검증

### ⚡ 빠른 검증 (개발 중 사용)

```bash
# 빠른 검증 실행
npm run check:quick
```

**실행되는 검증 항목:**
- ✅ 빌드 검증
- ✅ 타입 체크
- ✅ 린팅 검사

### 🔧 개별 검증

```bash
# 빌드만 검증
npm run check:build

# 테스트만 실행
npm run check:test

# 린팅만 검사
npm run check:lint

# 타입 체크만 실행
npm run check:type
```

## 🎯 사용 시나리오

### 📅 일일 작업 마무리
```bash
npm run check
```
모든 검증을 실행하여 프로젝트 상태를 확인합니다.

### 🔄 개발 중 빠른 체크
```bash
npm run check:quick
```
빌드와 타입 체크만 빠르게 실행합니다.

### 🚀 배포 전 최종 검증
```bash
npm run validate
```
배포 전 모든 검증을 실행합니다.

### 💾 커밋 전 검증
```bash
npm run pre-commit
```
커밋 전 빠른 검증을 실행합니다.

## 📊 결과 해석

### ✅ 성공
모든 검증이 통과하면 프로젝트가 배포 준비가 완료된 상태입니다.

### ❌ 실패
일부 검증에서 문제가 발견되면 해당 항목을 수정해야 합니다.

### ⚠️ 부분 성공
일부 검증만 통과하면 실패한 항목들을 우선적으로 수정해야 합니다.

## 🛠️ 스크립트 구조

```
scripts/
├── check-all.js      # 통합 검증 스크립트
├── quick-check.js    # 빠른 검증 스크립트
└── README.md         # 이 파일
```

## 🔧 커스터마이징

스크립트를 수정하여 검증 항목을 추가하거나 제거할 수 있습니다:

1. `scripts/check-all.js` - 통합 검증 스크립트 수정
2. `scripts/quick-check.js` - 빠른 검증 스크립트 수정
3. `package.json` - 새로운 스크립트 명령어 추가

## 📝 로그 레벨

스크립트는 다음 색상으로 상태를 표시합니다:

- 🟢 **초록색**: 성공
- 🔴 **빨간색**: 실패
- 🟡 **노란색**: 경고

## 🚀 CI/CD 통합

이 스크립트들은 CI/CD 파이프라인에서 사용할 수 있습니다:

```yaml
# .github/workflows/ci.yml
- name: Run all checks
  run: npm run check
```

스크립트 사용 중 문제가 발생하면 다음을 확인하세요:

1. Node.js 버전 (18.0.0 이상 권장)
2. npm 패키지 설치 상태
3. 환경 변수 설정
4. 권한 설정
