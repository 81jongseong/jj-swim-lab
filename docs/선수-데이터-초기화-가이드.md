# 🏊 선수 데이터 초기화 가이드

## 🎯 **"선수" 칩이 나타나는 이유**

### **원인**
```
LocalStorage에 저장된 테스트 데이터

저장 위치:
localStorage.getItem('swimlab.athletes.v1')

내용 예시:
[
  {
    "id": "ath_...",
    "name": "선수",  ← 기본값으로 생성된 것
    "icon": "🏊‍♂️",
    "conditionIds": []
  }
]

생성 시점:
- 예전에 테스트로 추가
- 또는 오류로 인한 기본값 저장
```

---

## 🗑️ **제거 방법**

### **방법 1: UI에서 삭제 (권장)**
```
1. "선수" 칩 클릭 (검은색으로 선택)
2. "🗑️ 삭제" 버튼 클릭
3. 확인

결과:
✅ "선수" 칩 사라짐
✅ LocalStorage에서 제거됨
```

### **방법 2: 브라우저 콘솔**
```
F12 (개발자 도구)
→ Console 탭
→ 아래 입력:

localStorage.removeItem('swimlab.athletes.v1');
location.reload();

결과:
✅ 모든 선수 데이터 초기화
✅ 페이지 새로고침
```

### **방법 3: 개별 확인 및 정리**
```
F12 → Console

// 현재 저장된 선수 확인
JSON.parse(localStorage.getItem('swimlab.athletes.v1') || '[]')

// 불필요한 선수만 제거
const athletes = JSON.parse(localStorage.getItem('swimlab.athletes.v1') || '[]');
const cleaned = athletes.filter(a => a.name !== '선수');
localStorage.setItem('swimlab.athletes.v1', JSON.stringify(cleaned));
location.reload();
```

## 🔍 **향후 방지**

### **코드 개선 (이미 완료)**
```
Before:
수동 추가 버튼 → prompt()로 이름 입력
→ 입력 안하면 기본값 "선수"

After:
회원 불러오기 → DB에서 실제 이름
→ "선수"라는 기본값 사용 안함
```
