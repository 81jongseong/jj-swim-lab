# 🏊 수영 트레이닝 엔진 - 탭 가이드

## 📊 탭 구조 개요

수영 트레이닝 엔진은 **6개의 주요 탭**으로 구성되어 있습니다.

---

## 1️⃣ 개요 (Overview)

### 목적
엔진의 전반적인 정보와 통계를 확인합니다.

### 주요 기능
- ✅ 엔진 통계 (생성된 프로그램 수, 평균 생성 시간, 성공률, 안전성 등급)
- ✅ 성능 지표 (처리 속도, 정확도, 안전성, 의학적 근거)
- ✅ 안전 기능 (의료진 검토 완료, 부상 위험 최소화)
- ✅ 엔진 설명 (시스템 개요 및 작동 원리)
- ✅ 데이터팩 정보 (질환 수, 훈련법 수, 드릴 수, 의학적 근거)

### 사용 시나리오
- 처음 페이지를 방문했을 때
- 엔진의 전반적인 상태를 확인하고 싶을 때
- 데이터팩의 규모를 파악하고 싶을 때

## 2️⃣ 컨디션 설정 (Condition Setup) ⭐ **신규**

### 목적
선수의 컨디션을 설정하고 팀 프로필을 관리합니다.

### 주요 기능

#### A. 팀/선수 프로필
- ✅ **회원 불러오기**: DB에서 실제 회원 정보 불러오기
  - 검색 기능 (이름/이메일)
  - 필터 기능 (학생/강사/전체)
  - 건강 정보 자동 매핑 (만성질환 → 컨디션)
- ✅ **선수 선택**: 다중 선택 가능 (칩 형태)
- ✅ **컨디션 저장**: 현재 선택한 컨디션을 선수에게 저장
- ✅ **목표 편집**: 선수의 목표 종목·기록 편집
- ✅ **불러오기**: 저장된 선수 프로필 불러오기
- ✅ **삭제**: 선수 프로필 삭제
- ✅ **팀 내보내기**: 여러 선수를 선택하여 일괄 ICS 생성

#### B. 컨디션 선택
- ✅ **클릭형 선택**: 주관식 없이 클릭만으로 선택
- ✅ **당일 컨디션** (ACUTE): 수면부족, 피로, 감기 등
- ✅ **만성 질환** (CHRONIC): 어깨 충돌, 무릎 통증 등
- ✅ **프리셋**: 자주 사용하는 조합을 슬롯에 저장/불러오기
- ✅ **View All**: 전체 컨디션 목록 검색/필터
- ✅ **규칙 커버리지**: 현재 매핑된 규칙의 비율 표시
- ✅ **룰 템플릿 내보기**: 미매핑 컨디션의 룰 템플릿 자동 생성

#### C. 선택 결과
- ✅ 선택된 컨디션 개수 표시
- ✅ conditionIds 배열 표시 (JSON 형식)
- ✅ 사용 예시 코드 제공

### 사용 시나리오
1. **개인 훈련 계획**
   ```
   회원 불러오기 → 컨디션 선택 → 저장 → 프로그램 생성
   ```

2. **팀 훈련 계획**
   ```
   여러 회원 불러오기 → 각자 컨디션 설정 → 
   여러 선수 선택 → 팀 내보내기
   ```

3. **코치 프리셋 사용**
   ```
   자주 사용하는 조합 → 슬롯에 저장 → 
   나중에 빠르게 불러오기
   ```

## 3️⃣ 훈련법 관리 (Training Methods)

### 목적
훈련법 데이터베이스를 관리하고 조회합니다.

### 주요 기능
- ✅ 훈련법 목록 조회 (카드 그리드 형태)
- ✅ 카테고리별 분류
  - Endurance (지구력)
  - Speed (스피드)
  - Technique (기술)
  - RaceStrategy (레이스 전략)
  - OpenWater (오픈워터)
- ✅ 훈련법 상세 정보 모달
  - 언제 사용하나요?
  - 누구에게 적합한가요?
  - 어떻게 하나요?
  - 강도와 볼륨
  - 장점/단점
  - 주의사항
  - 추천 드릴
  - 의학적 근거
- ✅ 훈련법 추가 (예정)

### 사용 시나리오
- 특정 훈련법의 상세 정보를 확인하고 싶을 때
- 새로운 훈련법을 배우고 싶을 때
- 의학적 근거를 확인하고 싶을 때

## 5️⃣ 질환별 가이드라인 (Conditions)

### 목적
28개 MSK 질환 + 40개 전체 질환의 가이드라인을 조회합니다.

### 주요 기능
- ✅ 질환 목록 조회 (카드 그리드 형태)
- ✅ 카테고리별 필터
  - 척추 (spine)
  - 무릎 (knee)
  - 어깨 (shoulder)
  - 고관절 (hip)
  - 발목 (ankle)
  - 팔꿈치 (elbow)
  - 손목 (wrist)
  - 피부 (skin)
  - 만성질환 (chronic)
  - 정신건강 (mental)
  - 특수상황 (special)
- ✅ 질환 상세 정보 모달
  - 질환 설명
  - 부위
  - 심각도 (경증/중등도/중증)
  - **6가지 영법별 상세 가이드**
    - 자유형 (Freestyle)
    - 배영 (Backstroke)
    - 평영 (Breaststroke)
    - 나비영 (Butterfly)
    - 기본 배영 (Elementary Backstroke)
    - 측영 (Sidestroke)
  - 각 영법별:
    - 안전도 (안전/주의/금지)
    - 상세 설명
    - 이유
  - 의학적 근거
  - 운동 제한사항
    - 강도 감소
    - 운동 시간
    - 주간 빈도
    - 금지 운동
    - 권장 운동

### 사용 시나리오
- 특정 질환을 가진 선수의 안전한 영법을 찾고 싶을 때
- 질환별 운동 제한사항을 확인하고 싶을 때
- 의학적 근거를 확인하고 싶을 때

## 🔄 일반적인 워크플로우

### 1. 개인 선수 프로그램 생성
```
① 개요 탭에서 엔진 확인
   ↓
② 컨디션 설정 탭으로 이동
   ↓
③ "회원 불러오기" 클릭
   ↓
④ 회원 검색/선택
   ↓
⑤ 추가 컨디션 선택 (필요시)
   ↓
⑥ "컨디션 저장" 클릭
   ↓
⑦ 프로그램 생성 (다른 시스템과 연동)
```

### 2. 팀 훈련 계획 생성
```
① 컨디션 설정 탭에서 여러 회원 불러오기
   ↓
② 각 회원에게 컨디션 설정 및 저장
   ↓
③ 여러 선수 선택 (칩 클릭)
   ↓
④ "팀 주간 계획 일괄 내보내기" 클릭
   ↓
⑤ 각 선수별 ICS 파일 자동 생성
```

### 3. 질환 연구 및 참고
```
① 질환별 가이드라인 탭으로 이동
   ↓
② 카테고리 필터 선택
   ↓
③ 질환 카드 클릭
   ↓
④ 6가지 영법별 가이드 확인
   ↓
⑤ 의학적 근거 및 제한사항 확인
```

## 💡 팁 & 트릭

1. **컨디션 설정 탭 활용**
   - 자주 사용하는 조합은 프리셋 슬롯(1~5)에 저장
   - 팀 훈련 시 한 번에 여러 선수 선택 가능
   - "View All"로 100개 이상의 컨디션 검색

2. **훈련법/드릴 탭 활용**
   - 카드 클릭으로 상세 정보 즉시 확인
   - 의학적 근거 링크로 논문 직접 확인 가능
   - 코칭 큐를 복사해서 선수에게 바로 전달

3. **질환별 가이드 활용**
   - 영법별 안전도를 즉시 확인
   - 운동 제한사항을 프로그램에 자동 반영
   - 의학적 근거로 선수/학부모에게 설명
