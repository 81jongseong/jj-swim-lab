# 🎯 체험 메뉴 재설계 - 관리자 설정 기반

**최종 업데이트:** 2025-01-22

---

## 💡 **핵심 아이디어**

```
❌ Before: 관리와 체험이 중복
✅ After: 관리자가 체험 콘텐츠를 설정
```

---

## 📋 **설계 원칙**

### 1️⃣ **관리자 페이지**
```
목적: 콘텐츠 생성, 수정, 삭제
권한: superAdmin, centerAdmin, admin
기능: 
  - CRUD 
  - "체험 모드 공개" 플래그
  - 우선순위 설정
```

### 2️⃣ **체험 페이지**
```
목적: 공개된 콘텐츠 보기/사용
권한: 모든 사용자 (guest 포함)
기능:
  - 읽기 전용
  - 공개된 항목만 표시
  - 비회원도 접근 가능
```

## 🏊‍♂️ **1. 영법 3D 뷰어**

### 현재 상태:
```
❌ 영법 종류 관리 (관리자) - 하드코딩
❌ 3D 수영 뷰어 (체험) - 빈 껍데기
→ 완전히 분리되어 있음
```

### 통합 후:
```
✅ 영법 종류 관리 (/admin/3d-viewer/swimming-styles)
   - 영법 CRUD (자유형, 배영, 평영, 접영...)
   - 3D 모델 업로드 (GLB/GLTF)
   - 난이도 설정
   - ✅ "체험 모드 공개" 체크박스
   - 우선순위 (정렬 순서)
   
           ↓ 필터링
   
✅ 3D 수영 뷰어 (/3d-viewer)
   - 공개된 영법만 표시
   - 3D 모델 렌더링 (Three.js)
   - 선택만 가능 (수정 불가)
   - 비회원 접근 가능
```

### 데이터 구조:
```typescript
interface SwimmingStyle {
  id: string;
  name: string; // 'freestyle'
  displayName: string; // '자유형'
  description: string;
  difficulty: 'beginner' | 'intermediate' | 'advanced';
  
  // 3D 관련
  modelUrl?: string; // GLB 파일 URL
  thumbnailUrl?: string; // 썸네일 이미지
  
  // 체험 모드 설정
  isPublicDemo: boolean; // ✅ 체험 모드 공개 여부
  demoOrder: number; // 체험 페이지 표시 순서
  
  isActive: boolean;
  createdAt: string;
  updatedAt: string;
}
```

## 🧠 **2. 퀴즈**

### 현재 상태:
```
❌ 퀴즈 관리 페이지 없음
✅ 퀴즈 체험 페이지 있음 (하드코딩)
→ 관리 기능 없음
```

### 통합 후:
```
✅ 퀴즈 관리 (/admin/quiz)
   - 퀴즈 CRUD
   - 문제 관리 (질문, 선택지, 정답)
   - 난이도, 카테고리, 제한시간 설정
   - ✅ "체험 모드 공개" 체크박스
   - 우선순위
   
           ↓ 필터링
   
✅ 퀴즈 체험 (/quiz)
   - 공개된 퀴즈만 표시
   - 퀴즈 풀기
   - 결과 확인
   - 비회원도 가능 (결과 저장 안됨)
```

### 데이터 구조:
```typescript
interface Quiz {
  _id: string;
  title: string;
  description: string;
  difficulty: 'easy' | 'medium' | 'hard';
  category: string;
  timeLimit: number; // 분
  
  questions: Question[];
  
  // 체험 모드 설정
  isPublicDemo: boolean; // ✅ 체험 모드 공개 여부
  demoOrder: number; // 체험 페이지 표시 순서
  
  isActive: boolean;
  createdAt: string;
  updatedAt: string;
}
```

## ✅ **장점**

### 1. 중복 제거
```
❌ Before: 관리 페이지와 체험 페이지 별도
✅ After: 하나의 데이터 소스
```

### 2. 유연한 관리
```
✅ 관리자가 체험 콘텐츠 직접 제어
✅ "체험 공개" 체크박스로 즉시 반영
✅ 우선순위로 순서 조정
```

### 3. 일관된 UX
```
✅ 모든 체험 콘텐츠가 동일한 방식
✅ 비회원도 명확하게 이해
✅ 관리자도 명확하게 관리
```

### 4. 확장성
```
✅ 추가 체험 콘텐츠도 동일한 패턴
✅ 드릴 체험, 건강체크 체험 등
```

## 🗑️ **제거 가능한 항목**

```
Option A: 체험 메뉴 완전 제거
  - 퀴즈 → /quiz (직접 접근)
  - 3D 뷰어 → /3d-viewer (직접 접근)
  
Option B: 체험 메뉴 유지 (추천)
  - 비회원을 위한 진입점
  - "체험해보기" 개념 명확
  - 마케팅 효과
```

### 🎯 **추천: Option B (유지)**
```
이유:
✅ 비회원에게 명확한 진입점 제공
✅ "체험" 개념이 마케팅에 유리
✅ 향후 더 많은 체험 콘텐츠 추가 가능
```
