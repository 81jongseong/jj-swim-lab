# 🏊 컨디션 선택 완벽 가이드

## 🎯 **선택박스와 검색의 차이**

### **1️⃣ 부위별 필터 (첫 번째 선택박스)**
```
목적: 특정 부위로 좁히기

예시:
- "전체" → 모든 컨디션 표시
- "어깨" → 어깨 관련만 표시
- "무릎" → 무릎 관련만 표시
- "허리" → 허리 관련만 표시
```

### **2️⃣ 태그 필터 (두 번째 선택박스)**
```
목적: 증상 유형으로 좁히기

예시:
- "전체" → 모든 태그
- "견관절" → 견관절 문제만
- "피로" → 피로 관련만
- "건" → 건 관련 질환만
```

### **🔍 검색창 (세 번째)**
```
목적: 자유롭게 검색

✅ 한글 가능: "어깨", "무릎", "허리"
✅ 영어 가능: "shoulder", "knee", "impingement"
✅ 부분 검색: "어" → 어깨 관련 모두 표시

예시:
- "어깨" 입력 → 17개의 어깨 관련 질환 표시
- "shoulder" 입력 → 동일 결과
- "건염" 입력 → 모든 건염 표시
```
