## 🚀 **완벽한 워크플로우**

### **Step 1: 회원 불러오기**
```
컨디션 설정 탭 이동
  ↓
"➕ 회원 불러오기" 클릭
  ↓
검색창에 이름 입력: "김영희"
  ↓
회원 카드 클릭
  ↓
자동 처리:
  - 70세 → 🔒 senior_65plus (자동)
  - 당뇨 → 🔒 diabetes_type2 (자동)
  - 염소 알레르기 → 🔒 chlorine_sensitivity (자동)
  ↓
"✅ 김영희님이 추가되었습니다!
 🔒 자동 설정된 컨디션: 3개"
```

### **Step 2: 당일 컨디션 추가**
```
김영희 칩 선택 (클릭)
  ↓
당일 컨디션 섹션에서:
  - "수면부족" 클릭 → 검은색으로 변경 ✅
  - "피로 高" 클릭 → 검은색으로 변경 ✅
  ↓
하단 확인:
  "✓ 선택됨 (5개): 
   senior_65plus, diabetes_type2, chlorine_sensitivity,
   sleep_deprived, fatigue_high"
```

### **Step 3: 컨디션 저장**
```
김영희 칩 선택됨 (검은색)
  ↓
"💾 컨디션 저장" 클릭
  ↓
"김영희에게 현재 컨디션이 저장되었습니다."
```

### **Step 4: 프로그램 생성**
```
프로그램 생성 패널에서:
  
타입: 주간 계획 (라디오 선택)
시작일: 2025-01-27
훈련일: 5일
거리: 6000m (65+ 감소)
풀: 25m
영법: 자유형
실력: 초급
CSS: 120초
신장: 160cm
  ↓
"🚀 주간 계획 생성" 클릭
  ↓
알림:
"✅ 1명의 주간 계획이 생성되었습니다!
 
 📥 ICS 파일 다운로드:
 Swim_Weekly_김영희.ics
 
 💾 웹에 저장 완료!
 → "프로그램 목록" 탭에서 확인하세요
 
 💡 다운로드 폴더 위치:
 C:\Users\사용자명\Downloads"
```

### **Step 5: 웹에서 확인**

## 🔒 **자동 컨디션 vs 수동 컨디션**

### **자동 컨디션 (영구, 수정 불가)**
```
기반: 건강정보
예시:
  - 🔒 65세 이상 (나이 70)
  - 🔒 당뇨 (만성질환)
  - 🔒 염소 알레르기

표시: 회색 배경, 자물쇠 아이콘
변경: 건강정보 수정 시만 변경
```

### **수동 컨디션 (임시, 자유 선택)**
```
기반: 당일 상태
예시:
  - ➕ 수면부족 (오늘만)
  - ➕ 피로 (오늘만)
  - ➕ 감기 (일시적)

표시: 흰색 배경, 클릭 가능
변경: 매번 자유롭게 선택
```

## 🎉 **전체 시스템 요약**

### **3단계 프로세스**
```
1. 회원가입 (1회)
   건강정보 입력 → MongoDB 저장

2. 프로그램 생성 (매번)
   회원 선택 → 건강정보 자동 로드 → 당일 컨디션 추가 → 생성

3. 확인 및 관리
   프로그램 목록 탭에서 모든 프로그램 관리
```

### **주요 개선점**
```
✅ 중복 입력 제거 (70% 시간 절약)
✅ 자동 변환 (나이 → 컨디션)
✅ 웹에서 바로 확인 (다운로드 필요 없음)
✅ 카드 형식 (직관적)
✅ 검색/필터 (빠른 찾기)
✅ 수정/삭제 (관리 용이)
```

## 💬 **FAQ**

### Q: 1번 선택박스와 2번 선택박스의 차이는?
```
A: 
1️⃣ 부위별 필터 (어깨, 무릎, 허리 등)
2️⃣ 태그 필터 (견관절, 피로, 건 등)
🔍 검색창 (한글/영어 자유 입력)

모두 사용 가능! 조합해서 사용하면 더 정확
```

### Q: "어깨"로 검색했는데 안나와요
```
A:
1. 필터 초기화: 1️⃣ "전체", 2️⃣ "전체"
2. 검색창에 "어깨" 입력
3. 또는 "🔍 전체 목록 열기" 클릭

결과: 17개 어깨 질환 표시!
```

### Q: "어깨 패키지" 버튼을 눌렀는데 변화가 없어요
```
A: 이미 선택되어 있을 수 있습니다.
확인: 하단 "✓ 선택됨 (N개)" 확인

클릭 시:
- 새로 추가: "✅ 3개 추가!"
- 이미 있음: "ℹ️ 이미 선택됨"
```

### Q: 파일이 어디 저장됐나요?
```
A: 2곳에 저장됩니다!

1. 다운로드 폴더 (.ics 파일)

2. 웹 (프로그램 목록 탭)

### Q: 프로그램 생성과 스케줄 생성은 다른가요?
```
A: 같은 기능입니다!

용어만 다를 뿐, 동일한 시스템:
  - 주간 계획 생성
  - 레이스 플랜 생성
  - ICS 다운로드

통합 완료! ✅

### Q: 건강정보는 매번 입력해야 하나요?
```
A: 아닙니다!

건강정보 (1회):
  - 회원가입 시 입력
  - MongoDB에 저장
  - 거의 수정 안함

컨디션 (매번):
  - 프로그램 생성 시마다
  - 자동 변환 + 수동 추가
  - 당일 상태 반영

예시:
회원가입: 나이 70, 당뇨
  ↓
프로그램 생성 시:
  - 자동: senior_65plus, diabetes_type2
  - 추가: 수면부족, 피로 (오늘만)
```
