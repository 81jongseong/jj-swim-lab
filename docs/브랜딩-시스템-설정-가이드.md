# 브랜딩 시스템 설정 가이드

## 현재 구현된 기능

### ✅ 구현 완료

1. **로고 업로드**
   - 위치: `/center/[centerSlug]/admin/home` 페이지
   - 방법: 
     1. 페이지 상단 "편집" 버튼 클릭
     2. "센터 로고 이미지" 섹션에서 파일 선택
     3. 자동 업로드 및 저장
   - API: `POST /api/centers/my-center/upload-logo`

2. **메인 이미지 업로드**
   - 위치: `/center/[centerSlug]/admin/home` 페이지  
   - 방법: 
     1. 페이지 상단 "편집" 버튼 클릭
     2. "메인 이미지" 섹션에서 파일 선택
     3. 자동 업로드 및 저장
   - API: `POST /api/centers/my-center/upload-main-image`

3. **브랜딩 자동 적용**
   - 업로드한 로고는 자동으로 다음 위치에 표시됩니다:
     - `DashboardLayout` 사이드바
     - `Navigation` 헤더
     - `TenantBranding`, `TenantLogo` 컴포넌트 사용 위치

### ❌ 아직 구현되지 않은 기능

1. **테마 색상 설정** (primaryColor, secondaryColor)
   - Center 모델의 `settings.theme.primaryColor`, `settings.theme.secondaryColor`에 저장 필요
   - 설정 API 및 UI 필요

2. **테마 모드 설정** (light/dark)
   - Center 모델의 `settings.theme.mode`에 저장 필요
   - 설정 API 및 UI 필요

## 브랜딩 데이터 구조

```typescript
// Center 모델
{
  images: {
    logo?: string;        // ✅ 업로드 가능
    mainImage?: string;   // ✅ 업로드 가능
  },
  settings: {
    theme: {
      primaryColor?: string;    // ❌ 설정 UI 없음
      secondaryColor?: string;  // ❌ 설정 UI 없음
      mode?: 'light' | 'dark';  // ❌ 설정 UI 없음
    }
  }
}
```

## 제안: 브랜딩 설정 페이지 생성

센터 관리자가 브랜딩을 한 곳에서 관리할 수 있는 전용 페이지를 만드는 것을 권장합니다:

**위치**: `/center/[centerSlug]/admin/settings` 또는 `/center/[centerSlug]/admin/branding`

**기능**:
1. 로고 업로드/미리보기
2. 메인 이미지 업로드/미리보기
3. 테마 색상 선택기 (primaryColor, secondaryColor)
4. 테마 모드 선택 (light/dark/auto)
5. 실시간 미리보기

## 현재 설정 가능한 방법

### 1. 로고 업로드 (✅ UI 있음)
**위치**: `/center/[centerSlug]/admin/home`
1. 페이지 접속
2. 상단 우측 "편집" 버튼 클릭
3. "센터 로고 이미지" 섹션에서 파일 선택
4. 자동 업로드 및 저장 완료

**API 직접 사용**:
```bash
POST /api/centers/my-center/upload-logo
Content-Type: multipart/form-data
Body: { logo: [파일] }
```

### 2. 메인 이미지 업로드 (✅ UI 있음)
**위치**: `/center/[centerSlug]/admin/home`
1. 페이지 접속
2. 상단 우측 "편집" 버튼 클릭
3. "메인 이미지" 섹션에서 파일 선택
4. 자동 업로드 및 저장 완료

**API 직접 사용**:
```bash
POST /api/centers/my-center/upload-main-image
Content-Type: multipart/form-data
Body: { mainImage: [파일] }
```

### 3. 테마 색상 설정 (❌ UI 없음, API로 가능)

현재는 API를 직접 호출해야 합니다. `PUT /api/centers/my-center` API에 `settings` 필드 처리를 추가해야 합니다.

**현재 API 구조**:
```typescript
PUT /api/centers/my-center
Body: {
  settings: {
    theme: {
      primaryColor: "#3b82f6",    // 예: 블루
      secondaryColor: "#8b5cf6",  // 예: 퍼플
      mode: "light" | "dark"       // 테마 모드
    }
  }
}
```

**참고**: 현재 서버 코드에서 `settings` 필드는 처리되지 않으므로, 먼저 서버 코드를 수정해야 합니다.
