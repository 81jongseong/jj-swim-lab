# 🚀 JJ Swim Lab 프로덕션 배포 가이드

## 📋 개요

JJ Swim Lab의 프로덕션 환경 배포를 위한 종합 가이드입니다. 성능 최적화가 완료된 상태에서 안전하고 효율적인 배포를 진행합니다.

## 🚀 배포 단계

### 1단계: 환경 변수 설정

```bash
# .env.production 파일 생성
NODE_ENV=production
NEXT_PUBLIC_API_URL=https://your-api-domain.com
NEXT_PUBLIC_APP_URL=https://your-app-domain.com
```

### 2단계: 프로덕션 빌드

```bash
# 클라이언트 빌드
cd client
npm run build:prod

# 서버 빌드
cd ../server
npm run build
```

### 3단계: 성능 검증

```bash
# 번들 분석
npm run bundle:analyze

# 성능 체크
npm run performance

# 번들 크기 확인
npm run bundle:size
```

### 4단계: 배포 실행

#### Vercel 배포 (권장)
```bash
# Vercel CLI 설치
npm i -g vercel

# 배포
vercel --prod
```

#### Docker 배포
```bash
# Docker 이미지 빌드
docker build -t jj-swim-lab .

# 컨테이너 실행
docker run -p 3000:3000 jj-swim-lab
```

#### 수동 서버 배포
```bash
# 정적 파일 업로드
scp -r .next/* user@server:/var/www/jj-swim-lab/

# 서버 재시작
ssh user@server "pm2 restart jj-swim-lab"
```
