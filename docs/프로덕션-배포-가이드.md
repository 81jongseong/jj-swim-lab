## 🔧 **환경 변수 설정**

### **클라이언트 (.env.production)**
```bash
# API 설정
NEXT_PUBLIC_API_URL=https://your-api-domain.com

# 환경 설정
NODE_ENV=production

# 앱 설정
NEXT_PUBLIC_APP_NAME=JJ Swim Lab
NEXT_PUBLIC_APP_VERSION=1.0.0

# 기능 플래그
NEXT_PUBLIC_ENABLE_ANALYTICS=true
NEXT_PUBLIC_ENABLE_PWA=true
NEXT_PUBLIC_ENABLE_OFFLINE=false

# 디버그 모드
NEXT_PUBLIC_DEBUG_MODE=false
```

### **서버 (.env.production)**
```bash
# 데이터베이스
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/jj-swim-lab-prod

# JWT 설정
JWT_SECRET=your-super-secret-jwt-key-here
JWT_EXPIRES_IN=7d

# 서버 설정
PORT=5000
NODE_ENV=production

# 보안 설정
CORS_ORIGIN=https://your-domain.com
RATE_LIMIT_WINDOW_MS=900000
RATE_LIMIT_MAX=100

# 로깅
LOG_LEVEL=info
LOG_FILE=logs/production.log
```

## 🔒 **보안 설정**

### **HTTPS 강제 적용**
```javascript
// next.config.js
const nextConfig = {
  async headers() {
    return [
      {
        source: '/(.*)',
        headers: [
          {
            key: 'Strict-Transport-Security',
            value: 'max-age=31536000; includeSubDomains'
          }
        ]
      }
    ]
  }
}
```

### **CORS 설정**
```javascript
// server/src/index.ts
app.use(cors({
  origin: process.env.CORS_ORIGIN || 'https://your-domain.com',
  credentials: true,
  methods: ['GET', 'POST', 'PUT', 'DELETE', 'OPTIONS'],
  allowedHeaders: ['Content-Type', 'Authorization']
}));
```

### **Rate Limiting**
```javascript
// server/src/middleware/rateLimit.ts
import rateLimit from 'express-rate-limit';

export const apiLimiter = rateLimit({
  windowMs: 15 * 60 * 1000, // 15분
  max: 100, // IP당 최대 요청 수
  message: '너무 많은 요청이 발생했습니다. 잠시 후 다시 시도해주세요.'
});
```

## 🔄 **CI/CD 파이프라인**

### **GitHub Actions 예시**
```yaml
name: Deploy to Production

on:
  push:
    branches: [main]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      
      - name: Setup Node.js
        uses: actions/setup-node@v2
        with:
          node-version: '18'
          
      - name: Install dependencies
        run: npm ci
        
      - name: Build application
        run: npm run build
        
      - name: Deploy to server
        run: |
          # 배포 스크립트 실행
          npm run deploy:prod
```
