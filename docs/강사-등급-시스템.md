# 🏆 JJ Swim Lab - 강사 등급 시스템

## 📋 **등급 체계**

### **🔰 신입 강사 (Trainee)**
**📊 승급 조건**
- ⏰ **경력**: 0-6개월
- 👥 **담당 학생**: 0-10명
- 📜 **자격증**: 기본 수영 지도자 자격증
- ✅ **체크리스트 완료율**: 60% 이상
- 📈 **학생 만족도**: 3.5/5.0 이상

**💰 혜택**
- 기본 급여: 100%
- 보너스: 없음
- 교육 지원: 신입 교육 프로그램

---

### **📈 주니어 강사 (Junior)**
**📊 승급 조건**
- ⏰ **경력**: 6개월-2년
- 👥 **담당 학생**: 10-30명
- 📜 **자격증**: 수영 지도자 + 안전 관리 자격증
- ✅ **체크리스트 완료율**: 75% 이상
- 📈 **학생 만족도**: 4.0/5.0 이상
- 🎯 **학생 승급률**: 70% 이상

**💰 혜택**
- 기본 급여: 110%
- 성과 보너스: 월 50만원
- 교육 지원: 전문 기술 교육

---

### **🏆 시니어 강사 (Senior)**
**📊 승급 조건**
- ⏰ **경력**: 2-5년
- 👥 **담당 학생**: 30-50명
- 📜 **자격증**: 전문 수영 지도자 + 특수 영법 자격증
- ✅ **체크리스트 완료율**: 85% 이상
- 📈 **학생 만족도**: 4.3/5.0 이상
- 🎯 **학생 승급률**: 80% 이상
- 🏊‍♂️ **특기 종목**: 2개 이상 전문 영법

**💰 혜택**
- 기본 급여: 125%
- 성과 보너스: 월 100만원
- 교육 지원: 해외 연수 기회
- 특별 수당: 특기 종목별 추가 수당

---

### **👑 마스터 강사 (Master)**
**📊 승급 조건**
- ⏰ **경력**: 5년 이상
- 👥 **담당 학생**: 50명 이상
- 📜 **자격증**: 마스터 트레이너 + 경기 지도자 자격증
- ✅ **체크리스트 완료율**: 90% 이상
- 📈 **학생 만족도**: 4.5/5.0 이상
- 🎯 **학생 승급률**: 90% 이상
- 👨‍🏫 **후배 멘토링**: 신입 강사 3명 이상 교육
- 🏆 **대회 실적**: 지도 학생 입상 실적

**💰 혜택**
- 기본 급여: 150%
- 성과 보너스: 월 200만원
- 교육 지원: 국제 자격증 취득 지원
- 리더십 수당: 팀 리더 역할 수당
- 주식 옵션: 센터 성과 연동 인센티브

## 🎯 **등급 평가 주기**

### **📅 정기 평가**
- **월간 평가**: 체크리스트 완료율, 학생 만족도
- **분기 평가**: 학생 승급률, 담당 학생 수
- **연간 평가**: 경력, 자격증, 종합 성과

### **🚀 즉시 승급**
- 모든 조건 달성 시 즉시 승급
- 특별한 성과 달성 시 조기 승급
- 대회 입상 지도 시 보너스 점수

### **⚠️ 등급 하락**
- 연속 3개월 기준 미달 시 경고
- 연속 6개월 기준 미달 시 등급 하락
- 안전사고 발생 시 즉시 등급 검토

## 💡 **자동화 시스템**

### **📊 데이터 수집**
```typescript
// 강사 성과 데이터 자동 수집
interface InstructorPerformance {
  instructorId: string;
  period: string; // 평가 기간
  
  // 기본 지표
  experienceMonths: number;        // 경력 (개월)
  currentStudentCount: number;     // 현재 담당 학생 수
  certifications: string[];        // 보유 자격증
  
  // 성과 지표
  checklistCompletionRate: number; // 체크리스트 완료율 (%)
  studentSatisfactionScore: number; // 학생 만족도 (1-5)
  studentPromotionRate: number;     // 학생 승급률 (%)
  
  // 추가 지표
  specialtyCount: number;          // 전문 영법 수
  mentoringCount: number;          // 멘토링한 신입 강사 수
  competitionResults: number;      // 대회 입상 지도 실적
}
```

### **🔄 자동 등급 계산**
```typescript
function calculateInstructorGrade(performance: InstructorPerformance): string {
  const score = 
    (performance.experienceMonths * 0.2) +
    (performance.currentStudentCount * 0.15) +
    (performance.checklistCompletionRate * 0.25) +
    (performance.studentSatisfactionScore * 20 * 0.2) +
    (performance.studentPromotionRate * 0.2);
    
  if (score >= 90) return 'Master';
  if (score >= 75) return 'Senior';
  if (score >= 60) return 'Junior';
  return 'Trainee';
}
```
