# 🚀 JJ Swim Lab 시스템 이전 완벽 가이드

## 📋 **시스템 개요**

**JJ Swim Lab**은 수영 강습을 위한 통합 관리 시스템입니다.
- **프론트엔드**: Next.js + TypeScript + Tailwind CSS + ShadCN
- **백엔드**: Express.js + MongoDB + JWT 인증
- **데이터베이스**: MongoDB Atlas (클라우드)
- **인증**: JWT 기반 RBAC (역할 기반 접근 제어)

## 🎯 **사용자 역할 및 권한**

### **1. 학생 (Student)**
- 강습법 학습 및 진행 상황 확인
- 체크리스트 관리
- 개인 대시보드

### **2. 강사 (Instructor)**  
- 학생 관리 및 체크리스트 관리
- 강습법 조회 및 적용
- 학생 진행 상황 추적

### **3. 센터 관리자 (Center Admin)**
- 센터별 강사 및 학생 관리
- 강습법 관리
- 센터 운영 통계

### **4. 슈퍼 관리자 (Super Admin)**
- 전체 시스템 관리
- 사용자 계정 관리
- 강습법 Excel 업로드 및 관리
- 시스템 설정

## 🛠️ **설치 및 실행 절차**

### **1. 필수 소프트웨어 설치**
```bash
# Node.js 18+ 설치 (https://nodejs.org/)
# Git 설치 (https://git-scm.com/)
# MongoDB Compass (선택사항, https://www.mongodb.com/try/download/compass)
```

### **2. 프로젝트 클론**
```bash
git clone [프로젝트-URL]
cd jj-swim-lab
```

### **3. 환경 변수 설정**
```bash
# server/.env 파일 생성
cp server/env.example server/.env
```

**필수 환경 변수:**
```env
# MongoDB Atlas 연결
MONGODB_URI=mongodb+srv://[사용자명]:[비밀번호]@[클러스터].mongodb.net/jjswimlab?retryWrites=true&w=majority

# JWT 시크릿
JWT_SECRET=[강력한-랜덤-문자열]

# 서버 포트
PORT=5000

# Redis (선택사항)
REDIS_URL=redis://localhost:6379
```

### **4. 의존성 설치**
```bash
# 서버 의존성 설치
cd server
npm install

# 클라이언트 의존성 설치  
cd ../client
npm install
```

### **5. 데이터베이스 연결 확인**
```bash
# MongoDB Atlas에서 데이터베이스 생성
# 데이터베이스명: jjswimlab
# 컬렉션: users, teachingMethods, courses, checklists, payments 등
```

### **6. 시스템 실행**
```bash
# 루트 디렉토리에서
.\start-both.bat

# 또는 수동으로
# 터미널 1 (서버)
cd server
npm run dev

# 터미널 2 (클라이언트)  
cd client
npm run dev
```

## 🔧 **주요 기능**

### **1. 사용자 인증 및 권한 관리**
- JWT 기반 로그인/로그아웃
- 역할 기반 접근 제어 (RBAC)
- 보안된 API 엔드포인트

### **2. 강습법 관리**
- Excel 파일 업로드 및 파싱
- 강습법 CRUD 작업
- 난이도별 분류 (초급/중급/고급)
- 단계별 설명 및 팁 관리

### **3. 학생 관리**
- 학생 정보 관리
- 체크리스트 생성 및 관리
- 진행 상황 추적

### **4. 대시보드**
- 역할별 맞춤형 대시보드
- 실시간 통계 및 현황
- 빠른 액세스 메뉴
- **모든 통계 카드 클릭 가능**: 각 카드 클릭 시 해당 기능 페이지로 즉시 이동
- **시각적 효과**: 호버 시 그림자, 확대, 테두리 효과로 상호작용 표시

## 🚨 **문제 해결**

### **1. 서버 연결 오류**
```bash
# 포트 확인
netstat -an | findstr :5000
netstat -an | findstr :3000

# 프로세스 종료
taskkill /F /IM node.exe
```

### **2. 데이터베이스 연결 오류**
- MongoDB Atlas IP 화이트리스트 확인
- 연결 문자열 검증
- 네트워크 연결 상태 확인

### **3. 의존성 설치 오류**
```bash
# npm 캐시 정리
npm cache clean --force

# node_modules 삭제 후 재설치
rm -rf node_modules
npm install
```

## 📊 **데이터베이스 스키마**

### **Users Collection**
```javascript
{
  _id: ObjectId,
  email: String,
  password: String,
  userType: String, // student, instructor, centerAdmin, superAdmin
  profile: {
    name: String,
    phone: String,
    address: String
  },
  // 역할별 추가 정보
  studentInfo: { /* 학생 정보 */ },
  instructorInfo: { /* 강사 정보 */ },
  centerAdminInfo: { /* 센터 관리자 정보 */ }
}
```

### **TeachingMethods Collection**
```javascript
{
  _id: ObjectId,
  name: String,           // 강습법 이름
  description: String,    // 설명
  level: String,          // 난이도 (beginner, intermediate, advanced)
  category: String,       // 카테고리
  steps: [String],        // 단계별 설명 (배열)
  tips: [String],         // 팁 (배열)
  videoUrl: String,       // 비디오 URL
  imageUrl: String,       // 이미지 URL
  isActive: Boolean,      // 활성 상태
  order: Number,          // 정렬 순서
  createdAt: Date,
  updatedAt: Date
}
```
