## 🔍 **페이지별 기능 분석**

### **1. `/user-role-integration` - 사용자 역할 통합 페이지**

#### **기능**
- 사용자 역할(최고관리자, 센터관리자, 강사, 수강생) 정보 표시
- 각 역할의 권한 목록 및 데이터 접근 권한 표시
- 역할 통합 설정 (권한 상속, 교차 역할 접근, 역할 변경 로그)

#### **구현 상태**
- ✅ 완전히 구현됨
- ✅ withAuth로 인증 보호됨
- ❌ 네비게이션 메뉴에 링크 없음

#### **용도**
- 관리자가 사용자 역할과 권한을 확인하고 설정하는 페이지
- 개발/테스트 목적으로 보임

#### **권장사항**
- **제거 권장**: 네비게이션에 링크가 없고, 실제 역할 관리는 다른 페이지에서 처리됨
- 또는 관리자 설정 페이지에 통합

---

### **2. `/personalized-dashboard` - 개인화 대시보드**

#### **기능**
- 진도 현황, 최근 활동, 성취도 카드 표시
- 대시보드 설정 (진도 현황 표시, 최근 활동 표시, 성취도 표시)

#### **구현 상태**
- ✅ 완전히 구현됨
- ✅ withAuth로 인증 보호됨
- ❌ 네비게이션 메뉴에 링크 없음
- ⚠️ 하드코딩된 더미 데이터 사용

#### **용도**
- 사용자가 대시보드를 개인화하는 페이지
- 데모/프로토타입으로 보임

#### **권장사항**
- **제거 권장**: 실제 대시보드(`/dashboard`)가 있고, 이 페이지는 데모용으로 보임
- 또는 실제 대시보드에 개인화 기능 통합

---

### **3. `/mobile-learning` - 모바일 최적화 학습 페이지** ⭐ **필요한 페이지**

#### **기능**
- 강습법 목록 표시 (카테고리, 레벨 필터링)
- 학습 진도 추적 (단계별 완료율)
- 학습 통계 (총 강습법, 완료, 진행중, 평균 진도)
- 단계별 학습 모달 (이전/다음 단계 네비게이션)
- 학습 팁 표시
- 로컬 스토리지에 진도 저장

#### **구현 상태**
- ✅ 완전히 구현됨
- ✅ API 연동 (`/api/teaching-methods`)
- ✅ 로컬 스토리지 진도 관리
- ✅ 모바일 최적화 UI
- ❌ 네비게이션 메뉴에 링크 없음

#### **용도**
- 모바일 환경에서 강습법을 학습하는 페이지
- 단계별 학습 진행 및 진도 추적

#### **권장사항**
- **유지 권장**: 실제 기능이 구현되어 있고, 모바일 사용자에게 유용함
- 네비게이션 메뉴에 추가 필요

---

### **4. `/membership` - 멤버십 관리 페이지** ⭐ **필요한 페이지**

#### **기능**
- 멤버십 플랜 관리 (생성, 조회)
- 사용자 멤버십 관리 (생성, 조회, 상태 관리)
- 결제 내역 관리
- 플랜별 기능 설정 (월 최대 강습, 비디오 업로드 수 등)
- 자동 갱신 설정

#### **구현 상태**
- ✅ 완전히 구현됨
- ✅ API 연동 (`/api/membership/*`)
- ✅ 관리자 권한 체크 (superAdmin, centerAdmin)
- ✅ withAuth로 인증 보호됨
- ❌ 네비게이션 메뉴에 링크 없음
- ✅ profile 페이지에서 언급됨

#### **용도**
- 관리자가 멤버십 플랜을 관리하고 사용자 멤버십을 관리하는 페이지
- 결제 시스템과 연동

#### **권장사항**
- **유지 권장**: 실제 비즈니스 로직이 구현되어 있고, 결제 시스템과 연동됨
- 네비게이션 메뉴에 추가 필요 (관리자 메뉴)

---

### **5. `/localization` - 언어 및 지역화 설정 페이지** ⭐ **필요한 페이지**

#### **기능**
- 언어 설정 (한국어, 영어, 일본어, 중국어)
- 지역 설정 (대한민국, 미국, 일본, 중국)
- 시간대 설정
- 날짜 형식 설정 (YYYY-MM-DD, MM/DD/YYYY 등)
- 시간 형식 설정 (24시간, 12시간)
- 통화 설정 (KRW, USD, JPY, CNY)
- 설정 미리보기
- 로컬 스토리지에 설정 저장

#### **구현 상태**
- ✅ 완전히 구현됨
- ✅ 로컬 스토리지 저장
- ✅ withAuth로 인증 보호됨
- ❌ 네비게이션 메뉴에 링크 없음

#### **용도**
- 사용자가 언어, 지역, 시간대 등을 설정하는 페이지
- 다국어 지원 및 지역화 기능

#### **권장사항**
- **유지 권장**: 다국어 지원을 위한 중요한 기능
- 프로필 페이지나 설정 페이지에 링크 추가 필요

---

### **6. `/accessibility` - 접근성 및 사용자 편의성 설정 페이지** ⭐ **필요한 페이지**

#### **기능**
- **시각적 설정**: 글자 크기, 고대비 모드, 색맹 지원, 모션 감소, 다크 모드
- **청각적 설정**: 소리 알림, 시각적 알림, 자막 크기
- **운동성 설정**: 큰 클릭 영역, 키보드 네비게이션, 음성 제어
- **인지적 설정**: 간소화된 레이아웃, 단계별 가이드, 자동 저장
- **개인화 설정**: 언어, 테마, 사용자 정의 색상
- 설정 내보내기/가져오기
- CSS 변수로 실시간 적용

#### **구현 상태**
- ✅ 완전히 구현됨
- ✅ 로컬 스토리지 저장
- ✅ CSS 변수로 실시간 적용
- ✅ withAuth로 인증 보호됨
- ❌ 네비게이션 메뉴에 링크 없음

#### **용도**
- 장애인 접근성 지원을 위한 포괄적인 설정 페이지
- WCAG 가이드라인 준수

#### **권장사항**
- **유지 권장**: 접근성은 중요한 기능이며, 법적 요구사항일 수 있음
- 프로필 페이지나 설정 페이지에 링크 추가 필요
