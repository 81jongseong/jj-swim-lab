# 🏊 Swim Engine v3.1 전략적 프로그램 생성 체계 확인

## ✅ **전략적 입력 요소**

### 1. **회원 프로필 기반**
- ✅ `level` (beginner/intermediate/advanced/master/expert) → 영법/드릴 필터링
- ✅ `strokesAllowed` (선호 영법) → 영법 선택 우선순위
- ✅ `strokesAvoid` (회피 영법) → 영법 제외
- ✅ `css100` (영법별 CSS) → 페이스 정밀 계산
- ✅ `goal` (목표) → 훈련법 우선순위 매핑 (25개 훈련법)
- ✅ `conditionIds` (질환/컨디션) → 강도/거리/영법 자동 조정 (28가지 규칙)

### 2. **이력 기반 전략**
- ✅ `weekHistory` (주간 훈련법 이력) → 3주 연속 방지, 다양성 확보
- ✅ 워밍업: 전 수업에서 기본배영/횡영 배웠으면 복습
- ✅ 테마 연속성: 전날 지구력 → 오늘 기술, 전날 기술 → 오늘 고강도

### 3. **컨디션 동적 조정**
- ✅ `dayCondition` (normal/tired/pain) → 실시간 강도 조정
- ✅ `hasPain` → 특정 영법/드릴 제외, 휴식 증가
- ✅ 질환별 차등 적용 (spine/shoulder/knee/ankle 카테고리)

## ✅ **워밍업 전략**

### 영법 선택 로직
```typescript
// 1. 레벨 필터: 사용자 설정 ∩ 레벨 허용 영법
finalAllowedStrokes = strokesAllowed.filter(s => levelAllowedStrokes.includes(s))

// 2. 복습 우선 (기본배영/횡영)
if (weekHistory.includes('elementary')) → elementary_backstroke
else if (weekHistory.includes('side')) → sidestroke
else → pickStroke('free') // 기본 영법

// 3. 선호/회피 반영
pickStroke(prefer: 'free' | 'back') {
  if (prefer === 'free' && finalAllowedStrokes.includes('freestyle')) return 'freestyle'
  if (finalAllowedStrokes.includes('backstroke')) return 'backstroke'
  return finalAllowedStrokes[0]
}
```

### 강도/페이스
- ✅ Zone 1 (CSS+16″) → 회복 강도
- ✅ RPE 1-2 → 편안함
- ✅ 휴식 10″ → 저강도 회복

## ✅ **PRE (준비) 블록 전략**

### 드릴 선택 (3축 기반)
```typescript
selectDrill(type, theme, goal, level)
  ├─ 1축: 목표 (goal) → 드릴 후보군 선택
  │   └─ 예: 기술 연마 → [Catch-Up, Scull, Zipper]
  ├─ 2축: 테마 (theme) → 드릴 우선순위
  │   ├─ tech_tempo → 기술 드릴 우선 (idx=0)
  │   ├─ endurance → 지구력 드릴 (idx=1)
  │   └─ tempo_hi → 고강도 드릴 (idx=2)
  └─ 3축: 레벨 (level) → DRILLS.who 필터
      ├─ beginner → '초보~중급', '모든 수준'
      ├─ intermediate → '초보~중급', '중급~상급', '모든 수준'
      └─ advanced+ → 모든 드릴
```

### 영법 분배
- ✅ Pull (팔) 드릴: 40% (기술 집중)
- ✅ Kick (킥) 드릴: 30% (지구력 지원)
- ✅ Combo (콤비네이션): 30% (빌드업/디센딩)
- ✅ 어깨 부상 시: 풀부이 제외
- ✅ 무릎/발목 부상 시: 킥보드 제외

## ✅ **MAIN (메인) 블록 전략**

### 훈련법 선택 (목표 기반)
```typescript
GOAL_TO_METHODS = {
  '체력 향상': [LSD, 풀 집중, 역치 인터벌, 템포 홀드, ...],
  '실력 향상': [역치 인터벌, 디센딩, USRPT, 스프린트, ...],
  '기술 연마': [스컬링, SPL, 킥 파워, 패들, 턴, ...],
  '체중 감량': [LSD, 하이-로우, 템포 홀드, IM 혼합, ...],
  '재활': [LSD, 풀 집중, 스컬링, SPL, 템포 홀드, ...],
  ...
}

// 이력 기반 로테이션
selectMethod(goal, weekHistory, dayIndex) {
  candidates = GOAL_TO_METHODS[goal]
  availableMethods = candidates.filter(m => !recentlyUsed(m, weekHistory))
  return availableMethods[dayIndex % availableMethods.length]
}
```

## ✅ **쿨다운 전략 (평영 균형 조절)**

### 영법 선택 로직
```typescript
// 1. 평영 사용량 분석
breastMeters = sets.filter(s => s.stroke === 'breaststroke').sum(s.meters)
breastRatio = breastMeters / totalMeters

// 2. 동적 선택 (상급 이상)
if (breastRatio > 0.4) {
  // 평영 과다 사용 (40%+)
  cdStroke = 'sidestroke'  // 횡영으로 상체 회복
  whySet = '횡영: 평영 과다 사용(40%+) 후 상체 회복, 편안한 쿨다운'
  
} else if (breastRatio < 0.1) {
  // 평영 거의 안함 (10%-)
  cdStroke = 'breaststroke'  // 평영 보완
  whySet = '평영 보완: 오늘 평영 부족(10% 미만), 쿨다운에서 균형 맞춤'
  
} else {
  // 평형적 사용
  cdStroke = 'sidestroke'  // 횡영 우선 (체력 절약형)
  whySet = '횡영: 체력 절약형 영법으로 쿨다운, 회복 시작'
}
```

### 강도
- ✅ Zone 1 (CSS+16″)
- ✅ 휴식 10″
- ✅ 거리: 50m 단위 (짧고 가벼움)

## ✅ **컨디션 기반 자동 조정**

### aggregateConditionRules (28가지 질환)
```typescript
mod = aggregateConditionRules(conditionIds, dayCondition, hasPain)

// 1. 강도 조정
mod.distanceMult: 0.6~1.0  // 질환 심각도에 따라 거리 감소
mod.restAdd: +5~+20″      // 휴식 증가

// 2. 영법 조정
mod.blockLimit: { WU: 0.8, PRE: 0.9, MAIN: 0.7, CD: 1.0 }
// 예: 어깨 부상 → MAIN 블록 30% 감소

// 3. 영법 제외
mod.strokeReplace: { butterfly: 'freestyle' }
// 예: 어깨 충돌증후군 → 접영 제외, 자유형 대체

// 4. 장비 제외
mod.equipmentExclude: ['pull_buoy', 'kickboard', 'paddles']
// 예: 어깨 부상 → 패들 제외
```

## ✅ **전략 요약**

```
입력
  ├─ 회원 프로필 (level, goal, strokesAllowed, strokesAvoid, css100)
  ├─ 질환/컨디션 (conditionIds, dayCondition, hasPain)
  └─ 이력 (weekHistory)

↓ 전략적 처리

워밍업 (10%)
  ├─ 영법: 전 수업 복습 (이력 기반) or 기본 영법
  ├─ 강도: Z1 (CSS+16″)
  └─ 목적: 체온·가동성 확보

PRE (15%)
  ├─ 드릴: 목표 + 테마 + 레벨 (3축)
  ├─ 영법: 레벨 필터 + 선호/회피
  └─ 목적: 기술 정렬, 메인 준비

MAIN (60%)
  ├─ 훈련법: 목표 기반 + 이력 로테이션
  ├─ 강도: 테마별 Zone 분배
  ├─ 영법: 선호 우선 + 레벨 제한
  └─ 조정: 질환별 거리/강도/휴식 자동 조정

쿨다운 (15%)
  ├─ 영법: 평영 균형 조절 (동적 분석)
  │   ├─ 40%+ → 횡영 (상체 회복)
  │   ├─ 10%- → 평영 (부족 보완)
  │   └─ 정상 → 횡영 (최적 회복)
  └─ 강도: Z1 (CSS+16″)

↓

출력
  ├─ 과학적 근거 (evidenceKeys)
  ├─ 설명 (whyPace, whyRest, whySet)
  └─ 이력 업데이트 (다음 세션 다양성)
```

## 🎯 **결론**

✅ **모든 프로그램은 전략적이고 과학적 근거 기반입니다**:

1. **입력 요소 완전 활용**:
   - level, goal, strokesAllowed, strokesAvoid, css100
   - conditionIds, dayCondition, hasPain
   - weekHistory

2. **동적 분석 및 조정**:
   - 평영 사용량 분석 → 쿨다운 영법 선택
   - 전날 테마 → 오늘 테마 연계
   - 질환 심각도 → 강도/거리/휴식 자동 조정

3. **이력 기반 다양성**:
   - 3주 연속 훈련법 방지
   - 워밍업 복습 (전 수업 내용)

4. **설명가능성**:
   - 모든 세트에 whyPace, whyRest, whySet
   - 과학적 근거 (evidenceKeys) 첨부

5. **레벨별 최적화**:
   - 초급: 기본 영법 + 초보 드릴
   - 상급: 전문 영법 + 고급 드릴
