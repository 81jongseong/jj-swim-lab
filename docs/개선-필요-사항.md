### **3. 레이스 플랜이 단조로움** 🟡
**문제**:
- "Base 0주 → Build 2주 → Peak 2주 → Taper 3주"
- 각 페이즈의 세부 프로그램이 단순함

**원인**:
- `raceProgramGenerator`가 `engine-v31`을 호출하지만
- 페이즈별 강도 분배만 다르고, 실제 훈련법은 동일

**개선 필요**:
- Base: LSD, 풀 집중 위주
- Build: 역치 인터벌, 템포 홀드
- Peak: 고강도, USRPT, 레이스 페이스
- Taper: 볼륨 감소, 기술 정확도

**파일**: `client/lib/swimlab/raceProgramGenerator.ts`

## 🎯 **추가 개선 제안**

### **1. 훈련법 레벨 필터** 🔵
**현재**:
- 드릴은 레벨 필터 있음
- 훈련법(25개)은 레벨 필터 없음

**개선**:
- TRAINING_METHODS에 `whoShouldUse` 필드 활용
- 초급: USRPT, 레이스 페이스 제외
- 상급: LSD만 계속 나오지 않도록

**근거**:
- 초급자에게 "레이스 페이스 USRPT"는 부적합
- 상급자에게 계속 "LSD"만 나오면 지루함

---

### **2. 컨디션별 운동량 조절 강화** 🔵
**현재**:
- `aggregateConditionRules`로 거리 조정
- 하지만 여러 질환 중첩 시 과도한 감소 가능

**개선**:
- 질환 중첩도 확인
- 최소 운동량 보장 (너무 줄지 않도록)
- 예: 3가지 질환 → 각각 -20% = -60% (너무 과함)
- 조정: Max(-40%) 제한

---

### **3. 요일별 연속성 강화** 🔵
**현재**:
- 전날 테마 확인 (`prevDayTheme`)
- 설명에만 반영, 실제 프로그램은 독립적

**개선**:
- 전날 고강도 → 오늘 회복 세션 (Z1 비율 증가)
- 전날 지구력 → 오늘 기술 집중 (드릴 비율 증가)
- 연속 피로도 고려

---

### **4. 주차별 점진적 부하 증가** 🔵
**현재**:
- 매주 동일한 거리/강도

**개선**:
- 1-3주차: 거리 점진 증가 (주당 +5-10%)
- 4주차: 디로드 (-20% 회복 주)
- 5주차: 다시 증가
- 근거: 선형 주기화 (Linear Periodization)

---

### **5. RPE 기반 자동 조정** 🔵
**현재**:
- RPE 표시만 (실제 사용 안함)

**개선**:
- 완료율 입력 시 feeling + RPE 수집
- 3세션 연속 'very_hard' → 다음 주 -10% 감소
- 3세션 연속 'easy' → 다음 주 +10% 증가

---

### **6. 영법 밸런스 전체 분석** 🔵
**현재**:
- 쿨다운에서만 평영 균형 조절

**개선**:
- 주간 전체 영법 분포 분석
- 자유형 80% 이상 → 다음 주 배영 비율 증가
- 4가지 영법 골고루 분배 (IM 준비)
