# JJ Swim Lab 프로젝트 요약

## 🏊‍♂️ 프로젝트 개요
JJ Swim Lab은 수영 강습을 위한 종합 관리 시스템으로, 강사, 학생, 센터 관리자가 효율적으로 수영 강습을 관리할 수 있는 플랫폼입니다.

## 🎯 주요 기능

### 1. 사용자 관리
- **강사 계정**: 학생 관리, 체크리스트 관리, 강습 계획 수립
- **학생 계정**: 개인 진행도 확인, 강습 예약, 학습 자료 접근
- **센터 관리자**: 센터 정보 관리, 강사 및 학생 관리
- **최고 관리자**: 시스템 전체 관리, 강습법 및 체크리스트 템플릿 관리

### 2. 체크리스트 시스템 (🔄 개선 중)
- **기존**: 개인별 체크리스트 생성 및 관리
- **개선**: 반 단위 체크리스트 + 학생별 진행도 추적
- **특징**: 
  - 반별 표준 체크리스트 (54개 강습법 단계 포함)
  - 학생별 개인 진행도 및 코멘트 관리
  - 강사의 효율적인 체크리스트 관리

### 3. 강습 관리
- **강습 예약**: 학생별 강습 일정 관리
- **진행도 추적**: 체크리스트 기반 학습 진행도 관리
- **강습법**: 초급/중급/고급별 체계적인 수영 강습법

### 4. 센터 관리
- **센터 정보**: 위치, 연락처, 시설 정보 관리
- **강사 관리**: 강사 프로필 및 스케줄 관리
- **수업 관리**: 반별 수업 일정 및 학생 관리

### 5. AI 분석 (계획)
- **자세 분석**: 수영 자세 AI 분석 및 피드백
- **성과 예측**: 학습 진행도 기반 성과 예측
- **개인화 추천**: 학생별 맞춤형 학습 경로 제안

## 🏗️ 기술 스택

### Frontend
- **Next.js 14**: App Router 기반 React 프레임워크
- **TypeScript**: 타입 안전성 보장
- **Tailwind CSS**: 모던 UI 디자인
- **Framer Motion**: 애니메이션 및 인터랙션

### Backend
- **Node.js**: 서버 런타임
- **Express.js**: 웹 프레임워크
- **TypeScript**: 타입 안전성 보장
- **Socket.IO**: 실시간 통신

### Database
- **MongoDB Atlas**: 클라우드 기반 NoSQL 데이터베이스
- **Mongoose**: MongoDB ODM

### DevOps
- **GitHub**: 소스 코드 관리
- **Vercel**: 프론트엔드 배포
- **GitHub Actions**: CI/CD 자동화
