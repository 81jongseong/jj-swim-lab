# 🏊‍♂️ JJ Swim Lab - 프로젝트 요약

## 📋 **프로젝트 개요**

**JJ Swim Lab**은 수영 강습 전문 플랫폼으로, 강사와 학생 간의 효율적인 수업 관리 및 건강 모니터링 시스템을 제공합니다.

## 🎯 **주요 기능**

### **👑 관리자 시스템**
- **슈퍼 관리자**: 전체 시스템 관리 및 모니터링
- **센터 관리자**: 센터별 운영 관리 및 강사 관리
- **대시보드**: 실시간 통계 및 현황 모니터링
  - 총 매출 관리 (`/admin/revenue`)
  - 승인 대기 관리 (`/admin/approvals`)
  - 사용자 통계 및 시스템 상태

### **🏊‍♂️ 강사 관리 시스템**
- 강사 등록 및 프로필 관리
- 수업 일정 및 학생 관리
- 강사별 성과 분석 및 평가
- 건강 관련 데이터 관리

### **📚 학생 관리 시스템**
- 수강 과정 등록 및 관리
- 개인 건강 프로필 관리
- 수업 예약 및 결제 시스템
- 학습 진도 추적

### **🏥 건강 관리 시스템**
- 개인 건강 정보 입력 및 관리
- 운동 계획 및 AI 추천 시스템
- 건강 데이터 공개/비공개 설정
- 권한별 데이터 접근 제어

## 🏗️ **기술 스택**

### **프론트엔드**
- **Next.js 14.2.5**: React 기반 풀스택 프레임워크
- **React 18.3.1**: 사용자 인터페이스 라이브러리
- **TypeScript 5.3.2**: 정적 타입 검사
- **Tailwind CSS**: 유틸리티 기반 CSS 프레임워크
- **Framer Motion**: 애니메이션 라이브러리

### **백엔드**
- **Express.js 4.18.2**: Node.js 웹 프레임워크
- **MongoDB Atlas**: 클라우드 NoSQL 데이터베이스
- **Mongoose**: MongoDB ODM
- **JWT**: 인증 토큰 관리

### **개발 도구**
- **pnpm**: 패키지 매니저 (모노레포 구조)
- **ESLint**: 코드 품질 관리
- **nodemon**: 서버 개발 자동 재시작

## 📊 **시스템 아키텍처**

### **클라이언트 (포트 3000)**
```
client/
├── app/                    # Next.js App Router
│   ├── admin/             # 관리자 페이지
│   │   ├── dashboard/     # 메인 대시보드
│   │   ├── revenue/       # 총 매출 관리
│   │   └── approvals/     # 승인 대기 관리
│   ├── instructor/        # 강사 전용 페이지
│   └── health/           # 건강 관리 페이지
├── components/            # 재사용 가능한 컴포넌트
├── hooks/                # 커스텀 React Hooks
└── lib/                  # 유틸리티 함수
```

### **서버 (포트 5000)**
```
server/
├── src/
│   ├── models/           # Mongoose 모델
│   ├── routes/           # API 라우트
│   ├── middleware/       # 미들웨어
│   └── index.ts         # 메인 서버 파일
├── scripts/              # 데이터베이스 스크립트
└── uploads/              # 파일 업로드 디렉토리
```
