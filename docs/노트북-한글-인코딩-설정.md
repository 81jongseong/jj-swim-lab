# 💻 노트북 한글 인코딩 설정 가이드

## 📋 문제 상황
Git 커밋 메시지나 파일명에서 한글이 깨져서 표시되는 문제

## ✅ 해결 방법

### 방법 1: Git 전역 설정 (권장)

노트북에서 다음 명령어를 실행하세요:

```bash
# Git 인코딩 설정
git config --global core.quotepath false
git config --global gui.encoding utf-8
git config --global i18n.commitencoding utf-8
git config --global i18n.logoutputencoding utf-8
```

**설명**:
- `core.quotepath false`: 파일명의 특수문자(한글 포함)를 그대로 표시
- `gui.encoding utf-8`: Git GUI에서 UTF-8 사용
- `i18n.commitencoding utf-8`: 커밋 메시지 인코딩을 UTF-8로 설정
- `i18n.logoutputencoding utf-8`: 로그 출력 인코딩을 UTF-8로 설정

### 방법 2: PowerShell 인코딩 설정

PowerShell에서 다음 명령어를 실행:

```powershell
# 코드페이지를 UTF-8로 설정
chcp 65001

# PowerShell 인코딩 설정
$OutputEncoding = [System.Text.Encoding]::UTF8
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$env:LESSCHARSET = 'utf-8'
```

### 방법 3: 배치 파일 사용 (자동화)

프로젝트 루트에 있는 `한글-터미널-설정.bat` 파일을 실행:

```bash
# 더블클릭으로 실행하거나
한글-터미널-설정.bat
```

## 🔍 설정 확인

설정이 제대로 적용되었는지 확인:

```bash
# Git 설정 확인
git config --get core.quotepath
git config --get i18n.commitencoding
git config --get i18n.logoutputencoding

# 예상 결과:
# false
# utf-8
# utf-8
```

## ⚠️ 주의사항

1. **이미 저장된 커밋 메시지는 수정 불가**
   - 과거 커밋 메시지의 한글 깨짐은 수정할 수 없습니다
   - 앞으로의 커밋 메시지만 정상적으로 표시됩니다

2. **터미널 재시작 필요**
   - 설정 후 터미널을 재시작하면 더 확실합니다

3. **Windows 터미널 사용 권장**
   - Windows Terminal을 사용하면 UTF-8 지원이 더 좋습니다

## 📝 테스트

설정 후 다음 명령어로 테스트:

```bash
# 한글 커밋 메시지 테스트
git log --oneline -5

# 한글이 정상적으로 표시되는지 확인
```

## 🔄 데스크탑과 동기화

데스크탑에서 이미 설정했다면:
- `--global` 옵션을 사용했으므로 같은 사용자 계정에서는 자동 적용
- 하지만 노트북에서도 위 명령어를 한 번 실행하는 것을 권장
