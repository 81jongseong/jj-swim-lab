# 🔧 JJ Swim Lab 환경 변수 설정 가이드

## 📋 개요

JJ Swim Lab의 프로덕션 환경 배포를 위한 환경 변수 설정 가이드입니다. 보안과 성능을 고려한 설정 방법을 제공합니다.

## 🔐 필수 환경 변수

### 1. 기본 환경 설정

```bash
# 환경 구분
NODE_ENV=production

# 애플리케이션 정보
APP_NAME=JJ Swim Lab
APP_VERSION=1.0.0
APP_PORT=5000
```

### 2. 데이터베이스 설정

```bash
# MongoDB Atlas 연결
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/jjswimlab?retryWrites=true&w=majority

# 데이터베이스 이름
DB_NAME=jjswimlab

# 연결 풀 설정
MONGODB_MAX_POOL_SIZE=10
MONGODB_MIN_POOL_SIZE=2
```

### 3. JWT 인증 설정

```bash
# JWT 시크릿 키 (강력한 랜덤 문자열 사용)
JWT_SECRET=your-super-secure-jwt-secret-key-here

# JWT 만료 시간
JWT_EXPIRES_IN=7d
JWT_REFRESH_EXPIRES_IN=30d

# JWT 발급자
JWT_ISSUER=jj-swim-lab
```

### 4. Redis 설정 (캐싱 및 세션)

```bash
# Redis 연결 정보
REDIS_URL=redis://localhost:6379
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=your-redis-password

# Redis 데이터베이스 번호
REDIS_DB=0

# Redis TTL 설정
REDIS_TTL=3600
```

### 5. 파일 업로드 설정

```bash
# 파일 업로드 경로
UPLOAD_PATH=./uploads

# 최대 파일 크기 (MB)
MAX_FILE_SIZE=10

# 허용된 파일 타입
ALLOWED_FILE_TYPES=image/jpeg,image/png,image/webp,application/vnd.openxmlformats-officedocument.spreadsheetml.sheet

# 클라우드 스토리지 (선택사항)
CLOUD_STORAGE_PROVIDER=aws
AWS_ACCESS_KEY_ID=your-aws-access-key
AWS_SECRET_ACCESS_KEY=your-aws-secret-key
AWS_REGION=ap-northeast-2
AWS_S3_BUCKET=jj-swim-lab-uploads
```

### 6. 이메일 설정 (알림용)

```bash
# 이메일 서비스
EMAIL_SERVICE=gmail
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your-email@gmail.com
EMAIL_PASSWORD=your-app-password

# 이메일 발송자 정보
EMAIL_FROM=JJ Swim Lab <noreply@jjswimlab.com>
EMAIL_REPLY_TO=support@jjswimlab.com
```

### 7. 결제 시스템 설정

```bash
# 결제 게이트웨이
PAYMENT_GATEWAY=toss
TOSS_CLIENT_KEY=your-toss-client-key
TOSS_SECRET_KEY=your-toss-secret-key

# 결제 성공/실패 URL
PAYMENT_SUCCESS_URL=https://your-domain.com/payment/success
PAYMENT_FAIL_URL=https://your-domain.com/payment/fail
```

### 8. 보안 설정

```bash

CORS_ORIGIN=https://your-domain.com
CORS_CREDENTIALS=true

# Rate Limiting
```

### 2. 환경 변수 검증

```bash
# 필수 환경 변수 체크
REQUIRED_ENV_VARS=(
  "NODE_ENV"
  "MONGODB_URI"
  "JWT_SECRET"
  "JWT_EXPIRES_IN"
)

for var in "${REQUIRED_ENV_VARS[@]}"; do
  if [ -z "${!var}" ]; then
    echo "Error: $var is not set"
    exit 1
  fi
done
```

## 🚀 배포 환경별 설정

### Vercel 배포

```bash
# Vercel 대시보드에서 환경 변수 설정
# 또는 vercel.json에서 설정
{
  "env": {
    "NODE_ENV": "production",
    "MONGODB_URI": "@mongodb-uri",
    "JWT_SECRET": "@jwt-secret"
  }
}
```

### Docker 배포

```bash
# docker-compose.yml
version: '3.8'
services:
  app:
    build: .
    environment:
      - NODE_ENV=production
      - MONGODB_URI=${MONGODB_URI}
      - JWT_SECRET=${JWT_SECRET}
    env_file:
      - .env.production
```

### PM2 배포

```bash
# ecosystem.config.js
module.exports = {
  apps: [{
    name: 'jj-swim-lab',
    script: 'dist/server.js',
    env: {
      NODE_ENV: 'production'
    },
    env_production: {
      NODE_ENV: 'production',
      MONGODB_URI: process.env.MONGODB_URI,
      JWT_SECRET: process.env.JWT_SECRET
    }
  }]
}
```

## 📊 환경 변수 검증 스크립트

```javascript
// scripts/validate-env.js
const requiredVars = [
  'NODE_ENV',
  'MONGODB_URI',
  'JWT_SECRET',
  'JWT_EXPIRES_IN'
];

const missingVars = requiredVars.filter(varName => !process.env[varName]);

if (missingVars.length > 0) {
  console.error('❌ Missing required environment variables:');
  missingVars.forEach(varName => console.error(`   - ${varName}`));
  process.exit(1);
}

console.log('✅ All required environment variables are set');
```

## 🔍 환경 변수 디버깅

```bash
# Node.js에서 확인
node -e "console.log('NODE_ENV:', process.env.NODE_ENV)"
```
