# 🔧 회원 다중 선택 시 개별 설정 시스템 개선

## 📌 **현재 문제점**

**BulkMemberVariablesModal**은 "일괄 적용" 모달:
- ❌ CSS 입력 1개 → 모든 회원에게 동일하게 적용
- ❌ 컨디션 선택 → 모든 회원에게 동일하게 적용
- ❌ 주영법 선택 → 모든 회원에게 동일하게 적용

**문제**: 개인마다 CSS, 컨디션, 영법이 다름!

---

## ✅ **해결 방안: 하이브리드 시스템**

### **1단계: 프로필 자동 로드 (새로운 기능)**

```typescript
// 회원 불러오기 시 각 회원의 프로필 자동 로드
interface MemberVariable {
  memberId: string;
  memberName: string;
  memberLevel: string;
  
  // 프로필에서 자동 로드
  css: {
    freestyle: number;      // 프로필.cssPer100.freestyle || 레벨 추정
    backstroke: number;
    breaststroke: number;
    butterfly: number;
  };
  conditionIds: string[];   // 프로필.conditionIds
  mainStrokes: Stroke[];    // 프로필.mainStrokes
  excludedStrokes: Stroke[]; // 프로필.excludedStrokes
  
  // 공통 설정 (모든 회원 동일)
  poolLength: number;
  sessionsPerWeek: number;
  sessionDuration: number;
  trainingDays: string[];
  goal: string;
}
```

### **Phase 1: 프로필 자동 로드 (High Priority)**

**파일**: `client/components/swimlab/BulkMemberVariablesModal.tsx`

```typescript
// 1. 회원 프로필 로드 함수
const loadMemberProfiles = async (members: any[]) => {
  const loaded = await Promise.all(
    members.map(async (member) => {
      try {
        // 프로필 API 호출
        const profile = await apiClient.get(`/api/users/${member._id}/swimming-profile`);
        
        return {
          memberId: member._id,
          memberName: member.name,
          memberLevel: member.studentInfo?.currentLevel || 'beginner',
          
          // 프로필에서 로드 (없으면 기본값)
          css: profile.cssPer100 || getEstimatedCSS(member.studentInfo?.currentLevel),
          conditionIds: profile.conditionIds || [],
          mainStrokes: profile.mainStrokes || ['freestyle'],
          excludedStrokes: profile.excludedStrokes || [],
          
          // 공통 설정 (초기값)
          poolLength: profile.poolLength || 25,
          sessionsPerWeek: 3,
          sessionDuration: 60,
          trainingDays: [],
          goal: profile.currentGoal || '체력 향상'
        };
      } catch (err) {
        console.error(`${member.name} 프로필 로드 실패:`, err);
        // 프로필 없으면 기본값
        return {
          memberId: member._id,
          memberName: member.name,
          memberLevel: member.studentInfo?.currentLevel || 'beginner',
          css: getEstimatedCSS(member.studentInfo?.currentLevel),
          conditionIds: [],
          mainStrokes: ['freestyle'],
          excludedStrokes: [],
          poolLength: 25,
          sessionsPerWeek: 3,
          sessionDuration: 60,
          trainingDays: [],
          goal: '체력 향상'
        };
      }
    })
  );
  
  setMemberVariables(loaded);
};

// 레벨 기반 CSS 추정
const getEstimatedCSS = (level: string) => {
  const baseCSS = {
    beginner: 150,
    intermediate: 120,
    advanced: 90,
    master: 75,
    expert: 70
  }[level] || 120;
  
  return {
    freestyle: baseCSS,
    backstroke: baseCSS + 10,
    breaststroke: baseCSS + 15,
    butterfly: baseCSS + 20
  };
};
```
