# 🏊 최적화된 워크플로우 - 원스톱 프로그램 생성

## 🎯 **새로운 워크플로우 개요**

### **Before (이전 방식) ❌**
```
1. 컨디션 설정 탭에서 입력
   - 회원 불러오기
   - 컨디션 선택
   - 저장

2. 다른 곳에서 프로그램 생성 버튼 클릭
   - 또다시 건강 정보 입력
   - 또다시 질환 정보 입력
   - 또다시 특수상황 입력
   
❌ 중복 입력!
❌ 단계가 많음!
❌ 헷갈림!
```

### **After (새로운 방식) ✅**
```
1. 컨디션 설정 탭에서 모두 완료
   - 회원 불러오기 (건강정보 자동 매핑)
   - 컨디션 선택
   - 프로그램 파라미터 입력
   - 🚀 바로 생성!

✅ 원스톱!
✅ 중복 없음!
✅ 간단명료!
```

## 📋 **단계별 가이드**

### **Step 1: 선수 선택**
```
① "➕ 회원 불러오기" 클릭
② 회원 검색/선택 (이름, 이메일, 실력 수준 확인)
③ 자동으로 선수 목록에 추가됨
   - 건강 정보 자동 매핑 ✅
   - 만성질환 → 컨디션 자동 변환 ✅
   - 알레르기 → 컨디션 자동 변환 ✅
```

### **Step 2: 추가 컨디션 선택 (선택사항)**
```
① 당일 컨디션 클릭 (수면부족, 피로 등)
② 추가 질환 클릭 (필요시)
③ 프리셋 사용 (자주 쓰는 조합)
```

### **Step 3: 컨디션 저장**
```
① 선수 칩 클릭 (1명 선택)
② "💾 컨디션 저장" 클릭
③ 선수 프로필에 저장됨
```

### **Step 4: 프로그램 생성 (NEW!)**
```
① 프로그램 타입 선택
   - 📅 주간 계획 (일상 훈련)
   - 🏆 레이스 플랜 (대회 준비)

② 파라미터 입력
   - 시작일
   - 주당 훈련일 (3~7일)
   - 주간 총 거리 (예: 8000m)
   - 풀 길이 (25m/50m)
   - 주 영법 (자유형/배영/평영/접영)
   - 실력 수준 (초급/중급/상급)
   - CSS/100m (초)
   - 신장 (cm)

③ 레이스 플랜 전용 (선택 시)
   - 대회 날짜
   - 테이퍼 주수 (1~3주)

④ 🚀 "프로그램 생성" 버튼 클릭!
   - 개인: 1명의 프로그램 생성
   - 팀: N명의 ICS 파일 일괄 다운로드
```

## 💡 **실제 사용 시나리오**

### **시나리오 1: 개인 학생 주간 계획**
```
상황: 김민수 학생의 이번 주 훈련 계획

① 회원 불러오기 → "김민수" 검색 → 선택
   자동 매핑: 어깨 충돌 + 중급 실력

② 추가 컨디션 선택: "수면부족" 클릭

③ 컨디션 저장 → 김민수 선택 → 저장

④ 프로그램 생성:
   - 타입: 주간 계획
   - 시작: 다음 월요일
   - 훈련일: 5일
   - 거리: 8000m
   - 풀: 25m
   - 영법: 자유형
   - 실력: 중급
   - CSS: 100초
   - 신장: 175cm

⑤ 🚀 생성 클릭!

결과:
✅ 어깨 충돌 회피: 접영 제외, 풀 강도 감소
✅ 수면부족 고려: 메인세트 단축, 드릴 위주
✅ 안전한 5일 계획 생성
```

### **시나리오 2: 팀 레이스 플랜**
```
상황: 3명의 선수, 3개월 후 대회 준비

① 회원 불러오기:
   - 김민수 (어깨 충돌)
   - 이지은 (정상)
   - 박준호 (무릎 통증)

② 각자 컨디션 저장

③ 3명 모두 선택 (칩 클릭)

④ 프로그램 생성:
   - 타입: 레이스 플랜
   - 대회: 3개월 후
   - 테이퍼: 2주
   - 거리: 12000m (강화 훈련)
   - 영법: 자유형

⑤ 🚀 생성 클릭!

결과:
✅ 3개의 ICS 파일 자동 다운로드:
   - Swim_Race_김민수.ics (어깨 보호)
   - Swim_Race_이지은.ics (풀 강도)
   - Swim_Race_박준호.ics (무릎 보호)
✅ 각자의 건강 상태 반영
✅ 구글 캘린더/아웃룩에 즉시 추가 가능
```

### **시나리오 3: 코치 프리셋 활용**
```
상황: 매주 반복되는 어깨 문제 선수 팀

① 프리셋 슬롯 1에 저장:
   - 어깨 충돌
   - 회전근개 과민
   - 견갑 불균형

② 새 학생 추가할 때마다:
   - 슬롯 1 불러오기 → 즉시 적용
   - 추가 당일 컨디션만 선택
   - 바로 프로그램 생성

⑤ 시간 절약:
   - 매번 3개 선택 (5분)
   - → 프리셋 1번 (5초)
   - 60배 빠름!
```

## 💬 **FAQ**

### Q: 기존에 저장된 선수 데이터는 어떻게 되나요?
A: 그대로 유지됩니다. 새 시스템은 기존 데이터를 모두 읽어올 수 있습니다.

### Q: 여러 선수를 선택했을 때 각자 다른 파라미터를 쓸 수 있나요?
A: 현재는 동일한 파라미터를 적용합니다. 각 선수의 컨디션만 자동으로 다르게 적용됩니다.

### Q: ICS 파일은 어떤 앱에서 열 수 있나요?
A: 구글 캘린더, 아웃룩, 애플 캘린더 등 모든 표준 캘린더 앱에서 사용 가능합니다.

### Q: 프로그램 생성 후 수정할 수 있나요?
A: 현재는 재생성만 가능합니다. 향후 편집 기능을 추가할 예정입니다.
