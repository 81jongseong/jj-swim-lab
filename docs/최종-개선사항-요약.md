#### **원인 분석**
```javascript
// Before: 간단한 템플릿 복사
sessions = selectedDays.map(day => {
  return {
    day: `${day}요일`,
    sets: [
      `웜업: 400m`,  // ← 모든 날 동일!
      `메인: 960m`,  // ← 모든 날 동일!
      `쿨다운: 200m` // ← 모든 날 동일!
    ]
  };
});
```

#### **해결 방법**
```javascript
// After: 실제 엔진 사용
sessions = selectedDays.map((day, dayIdx) => {
  // 각 요일마다 다른 목표
  const goals = ['Endurance', 'Tempo', 'Speed', 'Technique', 'Recovery'];
  const dailyGoal = goals[dayIdx % goals.length];
  
  // 실제 엔진으로 생성
  const program = buildProgram({
    goal: dailyGoal,          // ← 매일 다름!
    targetMeters: metersPerDay,
    methods: mergedMethods,   // ← 실제 108개 훈련법
    drills: mergedDrills,     // ← 실제 50개 드릴
    conditionIds: athlete.conditionIds,
    // ... 기타 파라미터
  });
  
  // WU, PRE, MAIN, CD 각각 다른 내용
  return { day, sets: [...] };
});
```

## 💡 **왜 이런 일이 생겼나?**

```

  → 간단한 템플릿만 복사
  → 모든 날 같은 내용

  → 108개 훈련법 활용 안됨

  → 모든 날 Endurance
  → 전문성 부족
```

✅ 컨디션 자동 적용
✅ SPL/Tempo/TT 계산
