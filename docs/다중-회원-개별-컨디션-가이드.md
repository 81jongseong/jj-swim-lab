# 🏊 다중 회원 개별 컨디션 시스템

## 🎯 **핵심 개념**

### **선수 클릭의 의미**
```
선수 칩 클릭 = 선택/해제 토글

용도:
1. 프로그램 생성 대상 선택
2. 컨디션 저장 대상 선택
3. 불러오기 대상 선택
4. 삭제 대상 선택

표시:
- 흰색: 선택 안됨
- 검은색: 선택됨 ✅
```

---

## 👥 **다중 회원 개별 컨디션 워크플로우**

### **Step 1: 여러 회원 불러오기**
```
"➕ 회원 불러오기 (다중 선택)" 클릭
  ↓
모달 열림
  ↓
여러 회원 선택:
  - 김민수 클릭 (파란색 테두리)
  - 이지은 클릭 (파란색 테두리)
  - 박준호 클릭 (파란색 테두리)
  ↓
하단: "✅ 3명 추가하기" 클릭
  ↓
자동 처리:
  - 김민수: senior_65plus, diabetes_type2
  - 이지은: (컨디션 없음)
  - 박준호: patellofemoral_pain
  ↓
"✅ 3명이 선수 목록에 추가되었습니다!"
```

### **Step 2: 각 선수별 컨디션 개별 설정**

#### **김민수의 컨디션 설정**
```
1️⃣ 김민수 칩 클릭 (검은색으로 변경)
   
   호버 시 툴팁:
   ┌──────────────────────────┐
   │ 김민수                   │
   │ 컨디션: 2개              │
   │ senior_65plus,           │
   │ diabetes_type2           │
   │ ✅ 선택됨               │
   └──────────────────────────┘

2️⃣ 추가 컨디션 선택:
   - "수면부족" 클릭
   - "피로 高" 클릭
   
   현재 컨디션:
   senior_65plus, diabetes_type2,
   sleep_deprived, fatigue_high

3️⃣ "💾 컨디션 저장" 클릭
   → 김민수에게 4개 컨디션 저장
```

#### **이지은의 컨디션 설정**
```
1️⃣ 김민수 칩 클릭 (검은색 → 흰색, 해제)
2️⃣ 이지은 칩 클릭 (흰색 → 검은색, 선택)

3️⃣ 컨디션 선택:
   - 모두 초기화 (이전 선택 지우기)
   - "근육통(DOMS)" 클릭
   - "생리 영향" 클릭
   
   현재 컨디션:
   doms, menstruation

4️⃣ "💾 컨디션 저장" 클릭
   → 이지은에게 2개 컨디션 저장
```

#### **박준호의 컨디션 설정**
```
1️⃣ 이지은 칩 클릭 (해제)
2️⃣ 박준호 칩 클릭 (선택)

3️⃣ 컨디션 확인:
   기본: patellofemoral_pain (무릎 PFPS)
   
4️⃣ 추가 선택:
   - "코감기/비염" 클릭
   
   현재 컨디션:
   patellofemoral_pain, upper_respiratory

5️⃣ "💾 컨디션 저장" 클릭
   → 박준호에게 2개 컨디션 저장
```

### **Step 3: 여러 선수 동시 선택하여 프로그램 생성**
```
1️⃣ 3명 모두 선택:
   - 김민수 클릭 (검은색)
   - 이지은 클릭 (검은색)
   - 박준호 클릭 (검은색)

2️⃣ 프로그램 생성 패널로 스크롤

3️⃣ 파라미터 입력 (공통):
   - 요일: 월, 수, 금 (3일)
   - 거리: 6000m
   - 풀: 25m
   - 영법: 자유형
   - CSS: 100초

4️⃣ "🚀 주간 계획 생성" 클릭

5️⃣ 자동 처리:
   각 선수의 저장된 컨디션을 자동으로 적용!
   
   김민수 프로그램:
   ✅ 컨디션: 4개 (senior_65plus, diabetes_type2, sleep_deprived, fatigue_high)
   ✅ 강도: 20% 감소 (65세+)
   ✅ 볼륨: 15% 감소 (당뇨)
   ✅ 메인 단축 (피로)
   
   이지은 프로그램:
   ✅ 컨디션: 2개 (doms, menstruation)
   ✅ 드릴 비중 증가 (근육통)
   ✅ 복압/킥 조절 (생리)
   
   박준호 프로그램:
   ✅ 컨디션: 2개 (patellofemoral_pain, upper_respiratory)
   ✅ 평영킥 회피 (무릎)
   ✅ 저호흡 회피, 잠수 제외 (감기)

6️⃣ 결과:
   3개 파일 다운로드:
   - Swim_Weekly_김민수.ics (65+ 안전 프로그램)
   - Swim_Weekly_이지은.ics (회복 위주 프로그램)
   - Swim_Weekly_박준호.ics (무릎 보호 프로그램)
```

## 💡 **핵심 포인트**

### **같은 파라미터, 다른 컨디션**
```
공통 파라미터:
✅ 요일: 월수금
✅ 거리: 6000m
✅ 풀: 25m
✅ 영법: 자유형

개별 컨디션:
✅ 김민수: 4개 (노인, 당뇨, 피로, 수면)
✅ 이지은: 2개 (근육통, 생리)
✅ 박준호: 2개 (무릎, 감기)

결과:
→ 3개의 완전히 다른 프로그램!
```

```
김민수 (65세, 당뇨):
━━━━━━━━━━━━━━━━━━━━━━
월요일: 1200m (20%↓)
  - 워밍업: 300m
  - 메인: 600m 지구력 (강도 ↓)
  - 쿨다운: 300m
  ⚠️ 고강도 회피, 휴식 충분

이지은 (근육통):
━━━━━━━━━━━━━━━━━━━━━━
월요일: 2000m (표준)
  - 워밍업: 400m
  - 메인: 800m 드릴 위주 (기술)
  - 쿨다운: 200m
  💡 근육통 회복, 기술 집중

박준호 (무릎):
━━━━━━━━━━━━━━━━━━━━━━
월요일: 2000m (표준)
  - 워밍업: 400m
  - 메인: 800m 평영 제외
  - 쿨다운: 200m
  ⚠️ 평영킥 회피, 킥 강도 ↓
```

## 🔄 **완전한 워크플로우 예시**

### **팀 훈련 계획 (5명)**
```
Day 1: 회원 불러오기
━━━━━━━━━━━━━━━━━━━━━━
"➕ 회원 불러오기 (다중 선택)"
→ 5명 선택
→ "✅ 5명 추가하기"

결과:
🏊‍♂️ 김민수
🏊‍♀️ 이지은
🏊‍♂️ 박준호
🏊‍♀️ 최서연
🏊‍♂️ 정우진

Day 2: 개별 컨디션 설정
━━━━━━━━━━━━━━━━━━━━━━
김민수 선택 → 컨디션 추가 → 저장
이지은 선택 → 컨디션 추가 → 저장
박준호 선택 → 컨디션 추가 → 저장
최서연 선택 → 컨디션 추가 → 저장
정우진 선택 → 컨디션 추가 → 저장

(각자 다른 컨디션!)

Day 3: 팀 프로그램 일괄 생성
━━━━━━━━━━━━━━━━━━━━━━
5명 모두 선택 (검은색)
→ 파라미터 입력 (공통)
→ "🚀 주간 계획 생성"

결과:
5개 파일 자동 생성!
각자의 컨디션이 반영됨!

- 김민수.ics (노인용)
- 이지은.ics (표준)
- 박준호.ics (무릎 보호)
- 최서연.ics (어깨 보호)
- 정우진.ics (회복 위주)
```

## 🎯 **시각적 변화 설명**

### **선수 클릭 시 변화**
```
Before 클릭:
┌──────────┐
│ 🏊 김민수 │ (흰색)
└──────────┘

After 클릭:
┌──────────┐
│ 🏊 김민수 │ (검은색, 흰 글자)
└──────────┘

호버 시:
┌──────────────────────────┐
│ 김민수                   │
│ 컨디션: 4개              │
│ senior_65plus,           │
│ diabetes_type2, ...      │
│ ✅ 선택됨               │
└──────────────────────────┘
```

### **다중 선택 시**
```
3명 선택:
┌──────────┐ ┌──────────┐ ┌──────────┐
│ 🏊 김민수 │ │ 🏊 이지은 │ │ 🏊 박준호 │
└──────────┘ └──────────┘ └──────────┘
  (검은색)      (검은색)      (검은색)

하단 표시:
"선택: 3명"

프로그램 생성 패널:
"선택된 선수: 3명 | 컨디션: 각자 다름"
```
