# 📥 노트북 프로젝트 업데이트 가이드

> **목적**: 데스크탑에서 작업한 내용을 노트북에 동기화하는 방법입니다.

---

## 🔄 **업데이트 방법**

### **방법 1: Git Pull (권장)**

노트북에서 다음 명령어를 실행하세요:

```bash
# 프로젝트 디렉토리로 이동
cd C:\Users\JJS\jj-swim-lab

# 현재 브랜치 확인
git branch

# 최신 변경사항 가져오기
git pull origin glb-debug-viewer

# 또는 단순히
git pull
```

### **방법 2: Cursor에서 Pull**

1. Cursor에서 프로젝트 열기
2. `Ctrl + Shift + P` (또는 `Cmd + Shift + P`)
3. "Git: Pull" 입력 후 선택
4. 또는 좌측 하단의 소스 제어 아이콘 클릭 → Pull 버튼 클릭

---

## ✅ **업데이트 확인**

업데이트 후 다음을 확인하세요:

```bash
# 최신 커밋 확인
git log --oneline -5

# 파일 변경사항 확인
git status
```

---

## 🚀 **업데이트 후 서버 실행**

업데이트가 완료되면:

```bash
# 서버 재시작
cd server
pnpm run dev

# 또는 start-server.bat 사용
cd ..
start-server.bat
```

---

## ⚠️ **주의사항**

- `.env` 파일은 Git에 포함되지 않으므로 노트북에 별도로 설정해야 합니다
- `node_modules`는 자동으로 설치되지만, 문제가 있으면 `pnpm install` 실행

---

## 🔍 **문제 해결**

### **충돌 발생 시**

```bash
# 현재 변경사항 백업
git stash

# 최신 변경사항 가져오기
git pull

# 백업한 변경사항 복원
git stash pop
```

### **로컬 변경사항이 있을 때**

```bash
# 로컬 변경사항 확인
git status

# 변경사항 커밋
git add .
git commit -m "로컬 변경사항"

# 그 다음 pull
git pull
```
