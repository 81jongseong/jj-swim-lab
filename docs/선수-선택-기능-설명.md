# 🏊 선수 선택 기능 완벽 가이드

## 🎯 **"선수" 칩을 클릭하면?**

### **동작: 선택/해제 토글**

```
┌────────────────────────────────────┐
│ 팀/선수 프로필                      │
│                                     │
│ [➕ 회원 불러오기]                 │
│                                     │
│ [🏊 김민수] [🏊 이지은] [🏊 박준호]│
│  ↑ 이 버튼들을 클릭!               │
└────────────────────────────────────┘
```

### **1차 클릭 (선택)**
```
Before:
┌──────────┐
│ 🏊 김민수 │ (흰색 배경, 검은 글자)
└──────────┘

클릭!
  ↓
After:
┌──────────┐
│ 🏊 김민수 │ (검은색 배경, 흰 글자)
└──────────┘

변화:
✅ 배경: 흰색 → 검은색
✅ 글자: 검은색 → 흰색
✅ 상태: 선택됨
✅ 하단: "선택: 1명" 표시

의미:
→ 이제 김민수가 "작업 대상"으로 선택됨
```

### **2차 클릭 (해제)**
```
Before:
┌──────────┐
│ 🏊 김민수 │ (검은색 배경, 흰 글자)
└──────────┘

다시 클릭!
  ↓
After:
┌──────────┐
│ 🏊 김민수 │ (흰색 배경, 검은 글자)
└──────────┘

변화:
✅ 배경: 검은색 → 흰색
✅ 글자: 흰색 → 검은색
✅ 상태: 선택 해제
✅ 하단: "선택: 0명"

의미:
→ 김민수 선택 취소
```

## 🔄 **선택이 필요한 작업들**

### **1️⃣ 컨디션 저장 (1명 선택 필요)**
```
상황:
현재 화면에서 컨디션 선택:
- shoulder_impingement
- sleep_deprived
- fatigue_high

저장하고 싶음!

방법:
1. 김민수 클릭 (검은색으로 변경)
2. "💾 컨디션 저장" 클릭
3. 완료!

결과:
→ 김민수의 프로필에 3개 컨디션 저장됨
→ 다음에 프로그램 생성 시 자동 적용
```

### **2️⃣ 컨디션 불러오기 (1명 선택 필요)**
```
상황:
저번에 저장했던 김민수의 컨디션을 다시 불러오고 싶음

방법:
1. 김민수 클릭 (검은색)
2. "📥 불러오기" 클릭
3. 완료!

결과:
→ 김민수의 저장된 컨디션이 화면에 자동 선택됨
→ 추가 수정 가능
```

### **3️⃣ 프로그램 생성 (여러 명 선택 가능)**
```
상황:
3명의 프로그램을 한 번에 만들고 싶음

방법:
1. 김민수 클릭 (검은색)
2. 이지은 클릭 (검은색)
3. 박준호 클릭 (검은색)
4. 프로그램 생성 패널로 스크롤
5. "🚀 주간 계획 생성" 클릭

결과:
→ 3개 프로그램 동시 생성
→ 각자의 저장된 컨디션 자동 적용
→ 3개 ICS 파일 다운로드
```

### **4️⃣ 삭제 (1명 선택 필요)**
```
상황:
박준호를 선수 목록에서 제거하고 싶음

방법:
1. 박준호 클릭 (검은색)
2. "🗑️ 삭제" 클릭
3. 확인

결과:
→ 박준호 선수 목록에서 삭제
```

## 👥 **다중 선택 예시**

### **3명 동시 선택**
```
초기:
┌──────────┐ ┌──────────┐ ┌──────────┐
│ 🏊 김민수 │ │ 🏊 이지은 │ │ 🏊 박준호 │
└──────────┘ └──────────┘ └──────────┘
  (흰색)        (흰색)        (흰색)

김민수 클릭:
┌──────────┐ ┌──────────┐ ┌──────────┐
│ 🏊 김민수 │ │ 🏊 이지은 │ │ 🏊 박준호 │
└──────────┘ └──────────┘ └──────────┘
  (검은색)      (흰색)        (흰색)
  
하단: "선택: 1명"

이지은 클릭:
┌──────────┐ ┌──────────┐ ┌──────────┐
│ 🏊 김민수 │ │ 🏊 이지은 │ │ 🏊 박준호 │
└──────────┘ └──────────┘ └──────────┘
  (검은색)      (검은색)      (흰색)
  
하단: "선택: 2명"

박준호 클릭:
┌──────────┐ ┌──────────┐ ┌──────────┐
│ 🏊 김민수 │ │ 🏊 이지은 │ │ 🏊 박준호 │
└──────────┘ └──────────┘ └──────────┘
  (검은색)      (검은색)      (검은색)
  
하단: "선택: 3명"

이제 프로그램 생성 → 3명 모두 생성!
```

## 💡 **호버(마우스 올리기) 기능**

### **선수 칩에 마우스 올리면**
```
┌──────────┐
│ 🏊 김민수 │ ← 마우스 올림
└──────────┘
     ↓
┌──────────────────────────┐
│ 김민수                   │
│ 컨디션: 4개              │
│ senior_65plus,           │
│ diabetes_type2,          │
│ sleep_deprived, ...      │
│ ✅ 선택됨               │
└──────────────────────────┘

정보 확인:
✅ 이름
✅ 컨디션 개수
✅ 컨디션 목록 (3개까지)
✅ 선택 상태
```

## 🎯 **요약**

### **선수 칩 클릭 = 체크박스처럼 동작**
```
클릭 → 선택 (검은색)
다시 클릭 → 해제 (흰색)

여러 명 선택 가능!

용도:
- 컨디션 저장 (1명)
- 컨디션 불러오기 (1명)
- 프로그램 생성 (N명)
- 삭제 (1명)
```

### **호버 = 미리보기**
```
마우스 올리기 → 툴팁 표시
→ 컨디션 확인
→ 선택 상태 확인
```
