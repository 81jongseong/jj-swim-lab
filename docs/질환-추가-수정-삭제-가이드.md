# 🏥 질환 추가/수정/삭제 가이드

## 🎯 **기능 개요**

### **질환 관리 시스템**
```
기본 질환: 60개 (고정, 수정 불가)
커스텀 질환: 무제한 (추가/수정/삭제 가능)

표시:
- 기본: [질환명] (수정/삭제 버튼 없음)
- 커스텀: [질환명] [✏️ 수정] [🗑️ 삭제]

자동 병합:
✅ 컨디션 설정에 즉시 반영
✅ 프로그램 생성에 즉시 사용
✅ 검색/필터 가능
```

---

## ➕ **질환 추가 방법**

### **Step 1: 질환별 가이드라인 탭 이동**
```
탭 메뉴
  ↓
"질환별 가이드라인" 클릭
```

### **Step 2: "+ 질환 추가" 버튼 클릭**
```
우측 상단:
┌────────────────────────────────┐
│ 질환별 가이드라인              │
│               [+ 질환 추가]    │
└────────────────────────────────┘
```

### **Step 3: 정보 입력**
```
1️⃣ 질환명 입력:
   "테니스 엘보"

2️⃣ 카테고리 입력:
   "팔꿈치"

3️⃣ 타입 선택:
   만성 질환인가요?
   → 확인 (CHRONIC)
   → 취소 (ACUTE - 당일 컨디션)
```

### **Step 4: 자동 생성 및 저장**
```
시스템이 자동으로:
✅ 고유 ID 생성 (custom_1706...)
✅ 기본 템플릿 적용
   - 6가지 영법별 안전도
   - 운동 제한사항
   - 의학적 근거 템플릿
✅ LocalStorage에 저장
✅ 즉시 목록에 추가

알림:
"✅ 테니스 엘보 질환이 추가되었습니다!
 → 즉시 컨디션 설정에 반영됩니다."
```

### **Step 5: 확인**
```
1. 질환 카드 목록에 추가됨
2. 컨디션 설정 탭 → 검색: "테니스" → 표시됨!
3. 프로그램 생성 시 사용 가능
```

## ✏️ **질환 수정 방법**

### **Step 1: 커스텀 질환 찾기**
```
질환별 가이드라인 탭
  ↓
필터 또는 검색으로 찾기
  ↓
커스텀 질환 카드 클릭
```

### **Step 2: 수정 버튼 확인**
```
상세 모달 헤더:

기본 질환 (예: 어깨 충돌):
┌────────────────────────────────┐
│ 질환별 가이드라인 상세 정보    │
│                            [✕] │
└────────────────────────────────┘

커스텀 질환 (예: 테니스 엘보):
┌────────────────────────────────┐
│ 질환별 가이드라인 상세 정보    │
│ [✏️ 수정] [🗑️ 삭제]    [✕]  │
└────────────────────────────────┘
```

### **Step 3: [✏️ 수정] 클릭**
```
수정 가능 항목:
- 질환명
- 카테고리
- 심각도
- 영법별 안전도
- 운동 제한사항
- 설명

(향후 구현 예정)
```

## 🗑️ **질환 삭제 방법**

### **Step 1: 커스텀 질환 상세 보기**
```
질환별 가이드라인 탭
  ↓
커스텀 질환 카드 클릭
  ↓
상세 모달 열림
```

### **Step 2: [🗑️ 삭제] 클릭**
```
확인 메시지:
"테니스 엘보"을(를) 삭제하시겠습니까?

[취소] [확인]
```

### **Step 3: 확인 클릭**
```
자동 처리:
✅ LocalStorage에서 제거
✅ 목록에서 즉시 사라짐
✅ 컨디션 설정에서도 제거됨

알림:
"✅ 질환이 삭제되었습니다!"
```

## 🔒 **기본 vs 커스텀 질환**

### **기본 질환 (60개)**
```
특징:
✅ 의료진 검토 완료
✅ 6가지 영법별 상세 가이드
✅ 의학적 근거 포함
✅ 수정/삭제 불가

예시:
- shoulder_impingement
- patellofemoral_pain
- lumbar_disc_herniation
```

### **커스텀 질환 (무제한)**
```
특징:
✅ 사용자가 추가
✅ 기본 템플릿 자동 적용
✅ 수정/삭제 가능
✅ 즉시 반영

예시:
- custom_1706... (테니스 엘보)
- custom_1707... (골퍼스 엘보)
```

## 📊 **자동 반영 시스템**

### **질환 추가 시**
```
질환 추가
  ↓
LocalStorage 저장
  ↓
getMergedConditions() 실행
  ↓
3곳에 즉시 반영:

1️⃣ 질환별 가이드라인 탭
   - 카드 추가
   - 필터 개수 업데이트

2️⃣ 컨디션 설정 탭
   - ConditionQuickPick에 추가
   - 검색 가능
   - 선택 가능

3️⃣ 프로그램 생성
   - 자동으로 룰 적용 (기본 템플릿)
   - 추천/회피 훈련법
```

### **질환 삭제 시**
```
질환 삭제
  ↓
LocalStorage에서 제거
  ↓
3곳에서 즉시 제거:

1️⃣ 질환별 가이드라인 탭
2️⃣ 컨디션 설정 탭
3️⃣ 프로그램 생성
```

## 🎯 **사용 예시**

### **시나리오: 테니스 엘보 질환 추가**

```
1. 질환별 가이드라인 탭
2. "+ 질환 추가" 클릭
3. 입력:
   - 질환명: 테니스 엘보
   - 카테고리: 팔꿈치
   - 타입: 만성 (확인)
4. 자동 생성 완료!

결과:
✅ 카드 추가됨
┌──────────────────────┐
│ ❤️ 테니스 엘보       │
│ 💡 주요 영향: 동작 제한│
│ 📍 부위: 팔꿈치      │
│ ⚠️ 심각도: 중등도   │
│ [✏️ 수정] [🗑️ 삭제]│
└──────────────────────┘

✅ 컨디션 설정에서 검색:
   "테니스" → 표시됨!

✅ 프로그램 생성 시:
   자동으로 안전 가이드 적용
```
