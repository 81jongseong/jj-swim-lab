## ⚠️ **검토 필요 (수동 처리)**

### 1. **nodemailer** (moderate)
- **현황**: `nodemailer@6.9.4` → `nodemailer@7.0.10` 업데이트 필요
- **취약점**: Email to an unintended domain can occur due to Interpretation Conflict
- **심각도**: Moderate
- **조치 방법**: 
  ```bash
  npm audit fix --force
  ```
- **주의사항**: 
  - ⚠️ **Breaking Change**: v7은 v6와 호환되지 않음
  - 업데이트 전 `emailService.ts` 코드 검토 필요
  - 이메일 발송 기능 테스트 필수
- **사용 위치**: 
  - `server/src/services/emailService.ts`
- **권장 조치**:
  1. `emailService.ts` 코드 검토
  2. 테스트 환경에서 업데이트 후 테스트
  3. 이메일 발송 기능 확인
  4. 프로덕션 배포 전 충분한 테스트

### 2. **xlsx** (high) ⚠️ **우선순위 높음**
- **현황**: `xlsx@0.18.5` - **수정 불가능** (No fix available)
- **취약점**: 
  - Prototype Pollution in sheetJS
  - Regular Expression Denial of Service (ReDoS)
- **심각도**: High
- **사용 위치**:
  - `server/src/routes/uploads.ts` (Excel 파일 업로드)
  - `server/src/utils/secureExcelParser.ts` (Excel 파싱)
  - `server/src/routes/member-bulk-import.ts` (회원 일괄 등록)
- **권장 조치**:
  1. **대안 라이브러리 검토**:
     - `exceljs` (이미 설치됨) - 더 안전한 대안
     - `node-xlsx` - 경량 대안
  2. **입력 검증 강화**:
     - Excel 파일 크기 제한
     - 파일 형식 검증
     - 업로드 전 바이러스 스캔 (선택사항)
  3. **사용자 입력 제한**:
     - 신뢰할 수 있는 사용자만 Excel 업로드 허용
     - 파일 크기 및 행 수 제한
  4. **모니터링**:
     - Excel 업로드 로그 기록
     - 이상 패턴 감지
