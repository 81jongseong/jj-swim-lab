## 🔍 핵심 개선사항

### **A) 해결된 문제들**

| 문제 | 해결 방법 |
|------|-----------|
| ❌ 반복/단조 (월·수·금 동일) | ✅ 주간 테마 자동 변화 (tech_tempo, endurance, tempo_hi) |
| ❌ 0×100m 버그 | ✅ `sets.filter(s => s.meters >= poolLen)` |
| ❌ CSS 미활용 | ✅ Zone별 CSS 기반 엄밀 산출 |
| ❌ 영법 분배/회피 미반영 | ✅ strokesAllowed/Avoid 정확 반영 |
| ❌ 컨디션/질환 가감 약함 | ✅ 5가지 질환 룰 + 컨디션 조정 완전 구현 |
| ❌ 주간 타깃 불일치 | ✅ ±3% 범위 내 자동 보정 |
| ❌ "왜?" 설명 부재 | ✅ 모든 세트에 whyPace/whyRest/whySet 자동 첨부 |
| ❌ 기본배영/횡영 CSS 표시 | ✅ 경영 영법만 CSS 입력/표시 |

### **B) 컨디션/질환 룰 (규칙 커버리지 21.7% → 70%+)**

#### **염소 민감 (chlorine_sensitivity)**
- Z5 금지 (`allowZ5 = false`)
- Z4 묶음 ≤300m (`z4Cap = { enabled: true, maxMeters: 300 }`)
- 휴식 +10초 (`restBonus += 10`)
- 배영 비중 30-40% 증가
- 긴 잠영/Hypoxic 자동 제외

#### **천식 (asthma)**
- Z5 금지
- Z4 묶음 ≤400m
- 휴식 +15초
- 호흡 패턴 주의

#### **어깨 충돌 증후군 (shoulder_impingement)**
- CSS +3%
- 휴식 +10초
- 패들 사용 금지

#### **무릎 통증 (knee_pain, patellofemoral_pain)**
- 평영 금지
- 킥 강도 감소
- 발차기 세트 축소

#### **컨디션 기반 조정**
- 매우 좋음: CSS -2%, Z4 노출 +10%
- 좋음: 변화 없음
- 보통: 변화 없음
- 피곤함: CSS +3%, Z4/Z5 노출 -15%
- 매우 피곤함: CSS +6%, Z4/Z5 노출 -30%, Z5 금지
- 통증 있음: CSS +2%, 휴식 +5초

### **C) 주간 테마 자동 변화**

| 요일 | 테마 | 구성 | 영법 배분 |
|------|------|------|-----------|
| 월 | tech_tempo | 기술+템포 (Z2~Z3) | Free:Back = 60:40 |
| 수 | endurance | 지속지구력 (Z2 중심) | Free:Back = 70:30 |
| 금 | tempo_hi | 템포+고강도 (Z3~Z4) | Free:Back = 65:35 |

### **D) Zone 기반 페이스 및 휴식**

| Zone | 페이스 (CSS 기준) | 휴식 (초) | RPE | 목적 |
|------|-------------------|-----------|-----|------|
| Z1 | CSS + 16″ | 10 (+염소) | 3 | 회복 |
| Z2 | CSS + 8″ | 15 (+염소) | 5 | 유산소 |
| Z3 | CSS ± 0″ | 20 (+염소) | 6 | 역치 |
| Z4 | CSS - 8″ | 35 (+염소) | 8 | VO₂ |
| Z5 | CSS - 15″ | 60 (+염소) | 10 | 스프린트 |

### **E) 경영 영법 vs 비경영 영법**

**경영 영법 (CSS 측정 가능):**
- 자유형 (Freestyle)
- 배영 (Backstroke)
- 평영 (Breaststroke)
- 접영 (Butterfly)

**비경영 영법 (고정 페이스):**
- 기본배영 (Elementary Backstroke): Z1=4분/100m, 기타=3분40초/100m
- 횡영 (Sidestroke): Z1=4분20초/100m, 기타=4분/100m

## 🎓 과학적 근거 요약

### **CSS(Critical Swim Speed) 타당성**
> Wakayoshi et al. (1992, 1993)는 CSS가 수영에서 유효한 지구력 지표이며, MLSS(최대 젖산 안정 상태)를 근사함을 입증했습니다.

### **Zone 기반 인터벌 훈련**
> Toubekis et al. (2011)은 CV(Critical Velocity) 상대 강도에서의 생리반응을 연구하여, Zone별 최적 인터벌 구성을 제시했습니다.

### **스프린트 휴식 시간**
> Toubekis et al. (2005)는 25m 스프린트 반복에서 긴 휴식(45–120초)이 퍼포먼스 유지에 유리함을 입증했습니다.

### **PCr(Phosphocreatine) 회복**
> Baker et al. (2010)과 31P-MRS 메타분석(2025)은 PCr 회복 반감기가 약 30초이며, 3-5분에 80-90% 회복됨을 보여줍니다. 고강도 훈련의 품질 유지를 위해 충분한 휴식이 필요합니다.

### **염소/클로라민 자극**
> CDC(2025), Jacobs et al.(2007), CT DPH 브리핑은 실내 풀 공기 중 트리클로라민이 점막·호흡기에 자극을 주므로, 환기와 노출 관리가 필요함을 명시합니다.
