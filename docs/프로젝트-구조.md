## 🔧 **주요 컴포넌트 상세 설명**

### **1. 클라이언트 컴포넌트**

#### **📱 네비게이션 컴포넌트**
- **`TopNavigation.tsx`**: 관리자용 고급 네비게이션
  - 그룹화된 드롭다운 메뉴
  - 권한별 메뉴 필터링
  - 모바일 반응형 햄버거 메뉴

- **`SimpleNavigation.tsx`**: 일반 사용자용 간단 네비게이션
  - 기본 메뉴 항목들
  - 사용자 타입별 메뉴 조정
  - PWA 설치 링크 포함

#### **🎨 UI 컴포넌트**
- **`Button.tsx`**: 다양한 스타일의 버튼 컴포넌트
  - `primary`, `secondary`, `outline`, `danger` 변형
  - 크기별 옵션 (`sm`, `md`, `lg`)
  - 로딩 상태 및 비활성화 지원

- **`Input.tsx`**: 폼 입력 필드 컴포넌트
  - 텍스트, 이메일, 비밀번호 등 타입 지원
  - 유효성 검사 및 오류 표시
  - 접근성 속성 지원

- **`Card.tsx`**: 카드 레이아웃 컴포넌트
  - 헤더, 본문, 푸터 구조
  - 그림자 및 테두리 옵션
  - 반응형 디자인

#### **🔐 인증 컴포넌트**
- **`AuthProvider`**: 전체 앱의 인증 상태 관리
  - JWT 토큰 관리
  - 사용자 정보 상태
  - 로그인/로그아웃 기능

### **2. 서버 컴포넌트**

#### **📊 데이터 모델**
- **`User.ts`**: 사용자 정보 및 권한 관리
  - 기본 사용자 정보 (이름, 이메일, 비밀번호)
  - 역할 기반 권한 (`superAdmin`, `centerAdmin`, `instructor`, `student`)
  - 센터별 정보 및 레벨 변경 이력

- **`CenterLevel.ts`**: 센터별 커스텀 레벨 관리
  - 레벨 이름, 표시명, 순서, 색상
  - 활성화/비활성화 상태
  - 센터별 고유 레벨 체계

- **`TeachingMethod.ts`**: 강습법 데이터 관리
  - 레벨별 강습법 분류
  - 센터별 레벨과 연동
  - Excel 파일 업로드 지원

#### **🛣️ API 라우트**
- **`auth.ts`**: 인증 관련 API
  - 로그인, 로그아웃, 토큰 검증
  - 사용자 등록 및 프로필 관리

- **`student-levels.ts`**: 학생 레벨 관리 API
  - 레벨 변경 및 이력 조회
  - 센터별 학생 레벨 통계
  - 권한별 접근 제어

- **`center-levels.ts`**: 센터별 레벨 관리 API
  - 커스텀 레벨 CRUD 작업
  - 레벨 순서 및 상태 관리

## 🔄 **데이터 흐름**

### **1. 사용자 인증 플로우**
```
1. 사용자 로그인 → 2. 서버 검증 → 3. JWT 토큰 발급
4. 클라이언트에 토큰 저장 → 5. API 요청 시 토큰 포함
6. 서버에서 토큰 검증 → 7. 권한 확인 → 8. 데이터 반환
```

### **2. 학생 레벨 변경 플로우**
```
1. 강사/센터관리자 로그인 → 2. 학생 목록 조회
3. 특정 학생 선택 → 4. 레벨 변경 모달 열기
5. 새 레벨 선택 및 사유 입력 → 6. 서버로 변경 요청
7. 서버에서 권한 확인 → 8. 데이터베이스 업데이트
9. 변경 이력 기록 → 10. 성공 응답 반환
```

### **3. 오프라인 데이터 동기화 플로우**
```
1. 온라인 상태에서 데이터 프리로딩 → 2. IndexedDB에 저장
3. 오프라인 상태에서 데이터 사용 → 4. 변경사항 로컬 저장
5. 온라인 복구 시 변경사항 서버로 전송 → 6. 동기화 완료
```
