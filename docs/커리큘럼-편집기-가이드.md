# 🎓 생존수영 & 인명구조원 커리큘럼 편집기 가이드

## 📋 **개요**

생존수영과 인명구조원 프로그램은 **표준 커리큘럼 기반**이지만, 강사가 각 센터와 학생 수준에 맞춰 **자유롭게 커스터마이징**할 수 있습니다.

---

## 🏊 **생존수영 커리큘럼 편집기**

### **기능**

#### 1️⃣ **차시 관리**
- ✅ **차시 추가**: 10차시 기본 → 무제한 확장 가능
- ✅ **차시 삭제**: 불필요한 차시 제거 (최소 1개 유지)
- ✅ **차시 순서 자동 재정렬**: 삭제 시 번호 자동 업데이트
- ✅ **Week/Day 수정**: 각 차시의 주차/요일 커스터마이징
- ✅ **시간 조정**: 30~180분 범위에서 자유 조정

#### 2️⃣ **활동 편집**
- ✅ **활동 추가/삭제**: 각 차시별 활동 커스터마이징
- ✅ **활동 타입**: 기술/드릴/시나리오/평가
- ✅ **세트 처방 수정**: `3×3′, r1′` 형식 자유 변경
- ✅ **설명 3종 필수**:
  - **Why Pace?**: 페이스 이유 (저강도 Z1 유지 등)
  - **Why Rest?**: 휴식 이유 (안전 확인, 교정 등)
  - **Why Set?**: 세트 목적 (생존기능 습득 등)

#### 3️⃣ **안전 수칙**
- ✅ **수칙 추가/삭제**: 각 차시별 안전 수칙 커스터마이징
- ✅ **수칙 수정**: 센터별 안전 규정 반영

### **사용 예시**

```typescript
import SurvivalSwimCurriculumEditor from '@/components/swimlab/SurvivalSwimCurriculumEditor';

<SurvivalSwimCurriculumEditor
  centerId="your-center-id"
  onSave={(sessions) => {
    // 커스터마이징된 커리큘럼 저장
    console.log('저장된 차시 수:', sessions.length);
  }}
  readOnly={false} // 편집 가능
/>
```

### **커스터마이징 시나리오**

#### **시나리오 1: 초등학교 3학년 (10차시 → 8차시 축소)**
```
원본 10차시:
- Week 1: 호흡+뜨기, 스컬링+트레드워터
- Week 2: HELP+이동, 안전입수+출수
- Week 3: 구조보조, 연속루프
- Week 4: 시나리오1, 시나리오2, 종합, 평가

축소 8차시:
- Week 1: 호흡+뜨기+스컬링 (차시1,2 통합)
- Week 2: 트레드워터+HELP, 안전입수
- Week 3: 구조보조, 연속루프
- Week 4: 종합시나리오, 평가

→ 차시 2개 삭제, 일부 통합, 시간 60분→50분
```

#### **시나리오 2: 고등학교 체육 (10차시 → 15차시 확장)**
```
확장 15차시:
- Week 1-2: 기초 (호흡, 뜨기, 스컬링, 트레드워터)
- Week 3-4: 생존기술 (HELP, 허들, 이동, 입수)
- Week 5: 구조보조 (던지기, 뻗기, 로프)
- Week 6-7: 고급 시나리오 (단독생존, 집단생존, 구조보조)
- Week 8: 평가 + 실전 시뮬레이션

→ 차시 5개 추가, 고급 기술 보강, 시간 50분→60분
```

## 🆘 **인명구조원 프로그램 편집기**

### **기능**

#### 1️⃣ **두 가지 프로그램 관리**
- **A) 5일 집중 과정**: 자격증 시험 대비 (480분/일)
- **B) 4주 준비 프로그램**: 사전 훈련 (60~90분/회, 주 3회)

#### 2️⃣ **5일 과정 편집**
- ✅ **Day 추가/삭제**: 5일 기본 → 무제한 확장
- ✅ **활동 타입**: 수영/구조/이론/CPR/시나리오
- ✅ **세트 처방 수정**: 수영 검정, 구조 드릴 등
- ✅ **Duration 조정**: 480분(8시간) 기본

#### 3️⃣ **4주 준비 편집**
- ✅ **Pool Sessions**: 각 주차별 수영 훈련 2회
  - 세트 이름, 처방, Why Pace/Rest/Set
- ✅ **Land Sessions**: 육상 훈련 1회
  - CPR, 코어, 경추 고정 등

### **사용 예시**

```typescript
import LifeguardProgramEditor from '@/components/swimlab/LifeguardProgramEditor';

<LifeguardProgramEditor
  centerId="your-center-id"
  onSave={(data) => {
    // 5일 과정 또는 4주 준비 저장
    console.log('5일 과정:', data.fiveDayCourse);
    console.log('4주 준비:', data.fourWeekPrep);
  }}
  readOnly={false}
/>
```

### **커스터마이징 시나리오**

#### **시나리오 1: 집중 3일 과정 (주말)**
```
원본 5일 → 축소 3일:
- Day 1: 수영 검정 + 구조 튜브 + 익수자 구조 (통합)
- Day 2: CPR/AED + 구조술 + 서피스 다이브 (통합)
- Day 3: 경추 부상 + 종합 평가

→ Day 2개 삭제, 시간 480분→600분(10시간)
```

#### **시나리오 2: 6주 준비 프로그램 (여유)**
```
원본 4주 → 확장 6주:
- Week 1-2: 기초 체력 (지구력 중심)
- Week 3-4: 역치 + 접촉/토우 (구조 기술)
- Week 5: 고강도 + 서피스 다이브
- Week 6: 시나리오 + 테이퍼

→ Week 2개 추가, 점진적 강도 증가
```

## 💾 **저장 및 관리**

### **저장 방식**

#### **1. 센터별 커스텀 커리큘럼**
```typescript
{
  centerId: "center-001",
  programType: "survival_swim",
  version: "custom_v1",
  sessions: [
    {
      sessionNumber: 1,
      week: 1,
      day: 1,
      title: "차시1: 호흡과 뜨기",
      duration: 50,
      activities: [...],
      safetyNotes: [...]
    },
    // ... 나머지 차시
  ],
  createdAt: "2025-01-09",
  updatedAt: "2025-01-09"
}
```

#### **2. 버전 관리**
- **표준 버전**: `standard_v1` (교육부 10차시)
- **커스텀 버전**: `custom_v1`, `custom_v2`, ...
- **센터 공유**: 다른 센터에 공유 가능

### **API 엔드포인트**

```typescript
// 저장
POST /api/curricula/survival-swim
POST /api/curricula/lifeguard

// 조회
GET /api/curricula/survival-swim/:centerId
GET /api/curricula/lifeguard/:centerId

// 표준 커리큘럼 복원
POST /api/curricula/survival-swim/reset
POST /api/curricula/lifeguard/reset
```

## 🎯 **활용 가이드**

### **생존수영 커스터마이징 팁**

#### ✅ **DO**
- 차시 수를 학생 수준에 맞춰 조정 (6~15차시)
- 안전 수칙을 센터 환경에 맞춰 추가
- Why Pace/Rest/Set 명확하게 작성 (ALT-PE 원칙)
- 시간을 학생 체력에 맞춰 조정 (30~60분)

#### ❌ **DON'T**
- 안전 수칙 삭제 금지 (최소 안전 기준 유지)
- 평가 차시 생략 금지 (성취 확인 필수)
- 고강도 활동 추가 금지 (생존수영은 Z1만)
- 거리/기록 목표 추가 금지 (기능 중심)

### **인명구조원 커스터마이징 팁**

#### ✅ **DO**
- CPR/AED 시간 늘리기 (최소 2시간 권장)
- 서피스 다이브 반복 횟수 증가 (8회→12회)
- 4주 준비를 6주로 확장 (여유 있는 훈련)
- Land Session 추가 (코어, 경추 집중)

#### ❌ **DON'T**
- 수영 검정 기준 낮추기 금지 (자격 요건)
- 경추 부상 대응 생략 금지 (필수 기술)
- 종합 평가 생략 금지 (자격증 조건)
- 고강도 과다 금지 (부상 위험)
