## 📊 기술적 구현 세부사항

### 프론트엔드 (Next.js + React)
- **Next.js 13+ App Router** 구조 적용
- **TypeScript** 인터페이스 정의
- **React Hooks** (useState, useEffect) 활용
- **컴포넌트 기반** 아키텍처

### 백엔드 연동
- **RESTful API** (`/api/users`) 호출
- **JWT 토큰** 기반 인증
- **센터별 데이터 필터링** 로직

### 데이터베이스 (MongoDB Atlas)
- **User 모델** 스키마 활용
- **센터별 사용자 관계** (assignedCenters, enrolledCenters)
- **ObjectId** 타입 처리

## 🔧 사용된 주요 기술

- **Frontend**: Next.js 13+, React 18, TypeScript, Tailwind CSS
- **Backend**: Node.js, Express, MongoDB Atlas
- **Authentication**: JWT (JSON Web Tokens)
- **Database**: MongoDB Atlas (Cloud)
- **Development**: Windows 환경, PowerShell
