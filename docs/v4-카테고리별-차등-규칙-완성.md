## 📊 28가지 관절질환 데이터 기반

### **기존 데이터 활용:**
`client/swim-training-engine/src/data/jj-swim-lab-joint-guidance.ts`

각 질환마다 6가지 영법별 가이드라인:
- **레벨**: safe / caution / avoid
- **이유**: 생체역학적 설명
- **허용 동작**: allowedMovements
- **금지 동작**: prohibitedMovements
- **수정사항**: modifications
- **대체 영법**: alternatives
- **의학 근거**: medicalEvidence

### **예시: 어깨 충돌 증후군**
```typescript
{
  conditionId: 'shoulder_impingement',
  conditionName: '어깨 충돌증후군',
  swimmingGuidance: {
    freestyle: {
      level: 'caution',  // 주의
      reason: '어깨 과사용 위험',
      prohibitedMovements: ['과도한 팔 올리기'],
      modifications: ['팔 동작 범위 축소']
    },
    backstroke: {
      level: 'safe',  // 안전
      reason: '어깨에 부담이 적음'
    },
    breaststroke: {
      level: 'safe',  // 안전 (오버헤드 적음!)
      reason: '어깨에 부담이 적음'
    },
    butterfly: {
      level: 'avoid',  // 회피
      reason: '어깨에 과도한 부담'
    }
  }
}
```

## 📚 과학적 근거 요약

### **CSS 유지 이유:**
> CSS는 역치(MLSS) 지표로서, 근골격계/호흡기 문제와 직접 연관 없음.  
> 부하 관리는 Zone 노출·장비·동작·휴식으로 조절.
> 
> **Evidence:** Wakayoshi 1992/1993, Toubekis 2011

### **Zone별 휴식 근거:**
> - Z4/Z5: PCr 재합성 반감기 ~30초, 완전 회복 3-5분  
> - Z3: 역치 반복 품질 유지 20-30초  
> - Z2: 기술 유지와 환기
> 
> **Evidence:** Toubekis 2005, Baker 2010, 31P-MRS 2025

### **염소 민감 관리:**
> 실내 풀 트리클로라민이 점막·호흡기 자극  
> → 노출/환기 시간 확보가 핵심
> 
> **Evidence:** CDC 2025, Jacobs 2007, CT DPH
