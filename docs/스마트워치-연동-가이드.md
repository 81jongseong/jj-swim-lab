# 🎯 SwimLab 스마트워치 연동 가이드

## 📋 개요

SwimLab의 훈련 프로그램을 스마트워치로 전송하여 운동 중 실시간 가이드를 제공합니다.

---

## 🔌 지원 플랫폼

### 1. Apple Watch (Apple Health)
- **연동 방식**: HealthKit API
- **지원 기능**:
  - 프로그램 전송 (workout 형식)
  - 실시간 HR 모니터링
  - VO2max 자동 수집
  - 수영 거리/시간 자동 기록

### 2. Garmin (Garmin Connect)
- **연동 방식**: Garmin Connect API + .FIT 파일
- **지원 기능**:
  - 프로그램 전송 (.FIT 파일)
  - 실시간 HR, 페이스 모니터링
  - Training Effect 자동 수집
  - 젖산역치 자동 수집

### 3. Polar (Polar Flow)
- **연동 방식**: Polar Flow API
- **지원 기능**:
  - 프로그램 전송
  - HR 모니터링
  - 회복 시간 예측

## 🛠️ 기술적 구현

### 1. 프로그램 변환

#### .FIT 파일 생성 (Garmin, Polar)

```typescript
// client/lib/smartwatch/fitFileGenerator.ts

interface FITWorkout {
  sport: 'swimming';
  subSport: 'lap_swimming' | 'open_water';
  steps: FITWorkoutStep[];
}

interface FITWorkoutStep {
  type: 'warmup' | 'active' | 'rest' | 'cooldown';
  durationType: 'distance' | 'time';
  durationValue: number;
  targetType: 'pace' | 'heart_rate';
  targetLow: number;
  targetHigh: number;
  intensity: 'active' | 'rest';
}

function convertProgramToFIT(program: WeeklyPlan, session: DayPlan): FITWorkout {
  const steps: FITWorkoutStep[] = [];
  
  session.sets.forEach(set => {
    // 워밍업/쿨다운 구분
    const type = set.desc.includes('워밍업') ? 'warmup' :
                 set.desc.includes('쿨다운') ? 'cooldown' : 'active';
    
    // 거리 또는 시간 기반
    const durationType = set.meters > 0 ? 'distance' : 'time';
    const durationValue = set.meters || (set.zone === 'Z1' ? 300 : 600); // 초 단위
    
    // 목표 페이스 (초/100m)
    const css100 = 90; // CSS 기반으로 계산
    const paceTarget = css100 * (set.zone === 'Z1' ? 1.18 : 
                                 set.zone === 'Z2' ? 1.09 :
                                 set.zone === 'Z3' ? 1.0 :
                                 set.zone === 'Z4' ? 0.95 : 0.9);
    
    steps.push({
      type,
      durationType,
      durationValue,
      targetType: 'pace',
      targetLow: paceTarget * 0.95,
      targetHigh: paceTarget * 1.05,
      intensity: type === 'rest' ? 'rest' : 'active'
    });
    
    // 휴식 세트 추가
    if (set.restSec > 0) {
      steps.push({
        type: 'rest',
        durationType: 'time',
        durationValue: set.restSec,
        targetType: 'heart_rate',
        targetLow: 60,
        targetHigh: 100,
        intensity: 'rest'
      });
    }
  });
  
  return {
    sport: 'swimming',
    subSport: 'lap_swimming',
    steps
  };
}
```

async function sendToAppleHealth(program: WeeklyPlan, session: DayPlan) {
  // HealthKit API 호출
  const workout = {
    activityType: 'HKWorkoutActivityTypeSwimming',
    startDate: new Date(session.date),
    duration: session.totalDuration * 60, // 분 → 초
    totalDistance: session.totalMeters,
    totalEnergyBurned: calculateCalories(session.totalMeters, session.totalDuration),
    metadata: {
      'SwimLab Program ID': program.id,
      'Theme': session.themeDesc,
      'Target Meters': session.totalMeters
    }
  };
  
  // iOS 앱을 통해 HealthKit에 저장
  if (typeof window !== 'undefined' && (window as any).webkit) {
    (window as any).webkit.messageHandlers.sendWorkout.postMessage(workout);
  }
}

## 📊 프로그램 전송 플로우

### 1. 프로그램 생성
```
사용자 → SwimLab → 레이스/주간 프로그램 생성
```

### 2. 스마트워치 연동 선택
```
프로그램 상세보기 → "📲 스마트워치로 전송" 버튼 클릭
```

### 3. 플랫폼 선택
```
- Apple Watch
- Garmin
- Polar
```

### 4. 프로그램 변환 및 전송
```
SwimLab 프로그램 → .FIT 파일 생성 → 스마트워치 앱으로 전송
```

### 5. 운동 실행
```
스마트워치 → 프로그램 실행 → 실시간 가이드 (페이스, HR)
```

### 6. 데이터 수집
```
스마트워치 → SwimLab으로 자동 업로드 (완료율, HR 데이터)
```

## 🚀 구현 단계

### Phase 1: 프로그램 전송 (현재)
- ✅ .FIT 파일 생성 로직
- ✅ Apple Health 연동 준비
- ✅ 프로그램 상세보기에 "전송" 버튼 추가

### Phase 2: 데이터 수집
- ⏳ 스마트워치에서 완료율 자동 업로드
- ⏳ HR 데이터 수집 및 저장
- ⏳ VO2max 자동 업데이트

### Phase 3: 실시간 조절
- ⏳ 당일 컨디션 자동 감지 (HR, 수면 질)
- ⏳ 실시간 강도 조절
- ⏳ 개인 맞춤형 알고리즘

## 💡 사용 예시

### 시나리오: 레이스 프로그램 전송

1. **프로그램 생성**:
   - 레이스 플랜 생성 (12주)
   - Base → Build → Peak → Taper

2. **스마트워치 전송**:
   - "📲 Garmin으로 전송" 버튼 클릭
   - .FIT 파일 다운로드
   - Garmin Connect에 업로드

3. **운동 실행**:
   - Garmin 워치에서 프로그램 실행
   - 세트별 가이드: "6×100m @ 1:15/100m, r20″"
   - 실시간 페이스 피드백

4. **자동 데이터 수집**:
   - 운동 종료 후 SwimLab에 자동 업로드
   - 완료율 85% (계획 2000m, 실제 1700m)
   - 평균 HR 150bpm
   - Training Effect 3.5

5. **다음 프로그램 자동 조절**:
   - 완료율 85% → 강도 유지
   - HR 데이터 → VO2max 업데이트
   - 다음 주 프로그램 자동 생성
