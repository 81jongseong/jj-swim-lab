- ✅ **pnpm** - 패키지 매니저 (npm/yarn 금지!)
- ✅ **Git** - 버전 관리

```bash

pnpm --version

# Git 설치 확인
git --version
```

## 🔧 **2단계: 환경 변수 설정**

### **2.1 서버 환경 변수 (.env 파일)**

서버 디렉토리에 `.env` 파일을 생성해야 합니다:

```bash
# server 디렉토리로 이동
cd server

# .env 파일 생성 (env.example 참고)
# Windows: 메모장 또는 VS Code에서 생성
notepad .env
```

### **2.2 .env 파일 내용**

데스크탑의 `server/.env` 파일 내용을 복사하거나, 다음 템플릿을 사용하세요:

```env
# =============================================================================
# 🔗 DATABASE CONFIGURATION
# =============================================================================
# MongoDB Atlas 연결 문자열 (데스크탑과 동일한 값 사용)
MONGODB_URI=mongodb+srv://username:password@cluster.mongodb.net/database?retryWrites=true&w=majority

# 샘플 데이터 생성 여부 (개발 환경에서는 false 권장)
CREATE_SAMPLE_DATA=false

# =============================================================================
# 🌐 SERVER CONFIGURATION
# =============================================================================
PORT=5000
NODE_ENV=development
CLIENT_URL=http://localhost:3000

# =============================================================================
# 🔐 JWT CONFIGURATION
# =============================================================================
# 데스크탑과 동일한 JWT_SECRET 사용 (인증 토큰 호환성을 위해)
JWT_SECRET=your-super-secret-jwt-key-here
JWT_EXPIRES_IN=7d

# =============================================================================
# 🚦 RATE LIMITING (Optional)
# =============================================================================
RATE_LIMIT_WINDOW_MS=60000
RATE_LIMIT_MAX_REQUESTS=100

# =============================================================================
# 📁 FILE UPLOAD (Optional)
# =============================================================================
UPLOAD_DIR=./uploads
MAX_FILE_SIZE=10485760

# =============================================================================
# 🔴 REDIS CONFIGURATION (Optional - 미사용)
# =============================================================================
# REDIS_HOST=localhost
# REDIS_PORT=6379
# REDIS_PASSWORD=
# REDIS_DB=0
```

### **2.3 중요 사항**

⚠️ **주의**: 
- `MONGODB_URI`는 데스크탑과 **동일한 값**을 사용해야 합니다 (같은 데이터베이스 사용)
- `JWT_SECRET`도 데스크탑과 **동일한 값**을 사용해야 합니다 (인증 토큰 호환성)
- 데스크탑의 `server/.env` 파일에서 값을 복사하는 것이 가장 안전합니다

### **2.4 클라이언트 환경 변수 (필요한 경우)**

클라이언트에도 환경 변수가 필요할 수 있습니다:

```bash
# 클라이언트 디렉토리로 이동
cd client

# .env.local 파일 생성
notepad .env.local
```

**클라이언트 .env.local 예시:**

```env
# API 서버 URL
NEXT_PUBLIC_API_URL=http://localhost:5000

# 기타 클라이언트 환경 변수 (필요한 경우)
```

## 🚀 **5단계: 개발 서버 실행**

## 🔧 **문제 해결**

### **문제 1: 포트 충돌**

포트 3000 또는 5000이 이미 사용 중인 경우:

```bash
# Windows에서 포트 사용 확인
netstat -ano | findstr :3000
netstat -ano | findstr :5000

# 프로세스 종료 (PID 확인 후)
taskkill /F /PID <PID번호>
```

### **문제 2: MongoDB 연결 실패**

- `.env` 파일의 `MONGODB_URI` 확인
- MongoDB Atlas IP 화이트리스트에 노트북 IP 추가 확인
- 네트워크 연결 확인

### **문제 3: 의존성 설치 오류**

```bash
# 캐시 정리 후 재설치
pnpm store prune
rm -rf node_modules
rm -rf server/node_modules
rm -rf client/node_modules
pnpm install
```

### **문제 4: 타입 오류**

```bash
# 타입 정의 재생성
cd server
npm run build

cd client
npm run build
```

## 💡 **팁**

1. **환경 변수 관리**: `.env` 파일은 Git에 커밋하지 마세요 (이미 `.gitignore`에 포함되어 있음)
2. **의존성 동기화**: `pnpm-lock.yaml` 파일은 Git에 커밋하여 데스크탑과 노트북 간 의존성 버전을 동일하게 유지
3. **포트 충돌**: 다른 개발 환경이 있다면 포트를 변경할 수 있습니다
4. **데이터베이스**: MongoDB Atlas를 사용하는 경우, 데스크탑과 노트북 모두 같은 데이터베이스를 사용하므로 데이터는 자동으로 동기화됩니다
