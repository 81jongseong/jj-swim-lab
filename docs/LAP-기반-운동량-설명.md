# 🏊 LAP(왕복) 기반 운동량 시스템

## 🎯 **왜 LAP 기준인가?**

### **현실적인 코칭 관행**
```
코치들은 원점 회귀식으로 운동량을 줍니다.

25m 풀:
- 1 LAP = 50m (왕복)
- 출발점 → 반환점 → 출발점

50m 풀:
- 1 LAP = 100m (왕복)
- 출발점 → 반환점 → 출발점

이유:
✅ 벽을 이용한 푸시오프
✅ 휴식 구간 명확
✅ 카운팅 용이
✅ 턴 연습 포함
```

## 📊 **Before vs After 비교**

### **Before (잘못된 방식)**
```
25m 풀에서:

❌ 웜업: 4×25m drill
   → 25m만 하고 멈춤 (비현실적)
   → 턴 연습 없음
   → 리듬 형성 어려움

❌ 메인: 8×25m 지구력
   → 너무 짧음
   → 유산소 효과 부족
   → 코치들은 안 씀

❌ 쿨다운: 2×25m
   → 너무 짧음
   → 회복 불충분
```

### **After (LAP 기준)** ✅
```
25m 풀에서:

✅ 웜업: 4×50m drill (4 LAP)
   → 왕복으로 리듬 형성
   → 턴 연습 포함
   → 충분한 워밍업

✅ 메인: 8×100m 지구력 (8 LAP × 2)
   → 적절한 거리
   → 유산소 효과
   → 현실적인 세트

✅ 쿨다운: 4×50m choice (4 LAP)
   → 충분한 회복
   → 부드러운 마무리
```

## 🔢 **거리 계산 공식**

### **LAP 정의**
```javascript
LAP = pool × 2

예시:
- 25m 풀: LAP = 50m
- 50m 풀: LAP = 100m
```

### **거리 스냅 (Snap to LAP)**
```javascript
// 모든 거리를 LAP 배수로 조정
snap(meters) = Math.round(meters / LAP) × LAP

예시 (25m 풀, LAP=50):
- 288m → 300m (6 LAP)
- 192m → 200m (4 LAP)
- 960m → 950m (19 LAP) 또는 1000m (20 LAP)
- 160m → 150m (3 LAP)
```

### **반복 횟수 계산**
```javascript
reps = Math.round(totalMeters / LAP)

예시 (25m 풀):
- 300m 워밍업 → 6×50m
- 200m 프리셋 → 4×50m
- 1000m 메인 → 10×100m (2 LAP씩)
- 150m 쿨다운 → 3×50m
```

## 💡 **피라미드 세트는?**

### **피라미드는 예외 처리**
```javascript
// 피라미드: 25-50-75-100-75-50-25
// → LAP 기준 적용 안함 (의도된 프로그레션)

if (isPyramid) {
  // 원래대로 유지
  return [25, 50, 75, 100, 75, 50, 25];
} else {
  // LAP 기준 적용
  return LAP 단위;
}
```

### **일반 세트는 LAP 기준**
```
일반 지구력 세트:
❌ 8×75m → 비현실적
✅ 8×100m → LAP 기준 (25m 풀: 2 LAP)
✅ 6×150m → LAP 기준 (25m 풀: 3 LAP)

일반 스프린트:
❌ 12×37.5m → 불가능
✅ 12×50m → LAP 기준
✅ 8×100m → LAP 기준
```

## 🔍 **변경 사항 요약**

### **코드 변경**
```javascript
// Before
const snap = (m) => Math.max(pool, Math.round(m/pool)*pool);
// 25m 단위로 스냅

// After
const LAP = pool * 2;
const snap = (m) => Math.max(LAP, Math.round(m/LAP)*LAP);
// 50m(25m 풀) 또는 100m(50m 풀) 단위로 스냅
```

## 💬 **FAQ**

### Q: 왜 25m 단위는 안쓰나요?
```
A: 코치들은 원점회귀식을 선호합니다.

이유:
1. 벽 푸시오프 활용
2. 휴식 지점 명확
3. 카운팅 용이
4. 턴 연습 포함
5. 리듬 형성

예외: 피라미드나 특수 드릴
```

### Q: 100m가 너무 길면?
```
A: 50m(1 LAP)로 자동 조정됩니다.

예시:
- 초급자: 10×50m (1 LAP)
- 중급자: 8×100m (2 LAP)
- 상급자: 6×150m (3 LAP) 또는 5×200m (4 LAP)
```

### Q: 피라미드 세트는?
```
A: 피라미드는 예외 처리 (향후 구현)

현재: 일반 세트만 LAP 기준
향후: 피라미드 감지 및 별도 처리
```
