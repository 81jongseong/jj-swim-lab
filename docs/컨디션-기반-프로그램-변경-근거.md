## 🔬 **엔진 내부 동작**

### **1단계: 규칙 조회**
```javascript
// engine.ts
const multi = conditionIds ? applyRulesMulti(conditionIds) : null;

if (multi) {
  // 회피 훈련법 제외
  if (multi.avoidMethods.length) {
    poolMethods = poolMethods.filter(m => 
      !multi.avoidMethods.includes(m.id)
    );
  }
  
  // 추천 훈련법 우선
  if (multi.recommendMethods.length) {
    poolMethods = [...poolMethods].sort((a,b) =>
      (multi.recommendMethods.includes(a.id) ? -1 : 0) - 
      (multi.recommendMethods.includes(b.id) ? -1 : 0)
    );
  }
}
```

### **2단계: 프로그램 생성**
```javascript
// 필터링된 훈련법으로만 프로그램 생성
const pick = poolMethods.slice(0, 3);  // 상위 3개

for (const m of pick) {
  // 안전한 훈련법만 사용!
  MAIN.push({ 
    name: `Main: ${m.title}`, 
    items: [...] 
  });
}
```

### **3단계: 참고사항 추가**
```javascript
notes.push(`조건 적용: ${multi.normalized.join(', ')}`);
multi.rationale.forEach(r => notes.push(r));
```

## 🎯 **자동 조정 항목**

### **1. 훈련법 선택**
```
조건 없음:
→ 목표에 맞는 훈련법 무작위 선택

조건 있음:
→ 회피 훈련법 완전 제외
→ 추천 훈련법 우선 선택
→ 안전한 훈련법만 사용
```

### **2. 드릴 선택**
```
조건 없음:
→ 일반 드릴

조건 있음:
→ 위험 드릴 제외 (평영 킥, 패들 등)
→ 안전 드릴 우선 (스컬링, 정렬 등)
```

### **3. 강도 조절**
```
조건 없음:
→ 표준 Zone (Z1~Z5)

조건 있음:
→ Zone 제한 (예: Z5 → Z3)
→ 페이스 느리게
→ 휴식 증가
```

### **4. 볼륨 조절**
```
조건 없음:
→ 100% 볼륨

조건 있음:
→ 10~30% 감소 (조건에 따라)
→ 세트 수 감소
→ 반복 횟수 조정
```

### **5. 참고사항 추가**
```
모든 프로그램에 포함:
✅ 적용된 조건 목록
✅ 각 조건의 rationale
✅ 의학적 근거 (논문 링크)
✅ 충돌 해결 내역
```
