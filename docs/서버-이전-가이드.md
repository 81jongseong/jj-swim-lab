## 🔧 **수동 설치 단계**

### **1단계: 환경 요구사항 확인**
```bash
# Node.js 버전 확인 (18+ 권장)
node --version

# npm 버전 확인
npm --version

# Git 버전 확인
git --version

# pnpm 설치 (없는 경우)
npm install -g pnpm
```

### **2단계: 프로젝트 복사**
```bash
# Git 클론
git clone <repository-url>
cd jj-swim-lab

# 또는 압축 파일 해제 후
# 프로젝트 디렉토리로 이동
```

### **3단계: 의존성 설치**
```bash
# 루트 의존성 설치
pnpm install

# 클라이언트 의존성 설치
cd client
pnpm install
cd ..

# 서버 의존성 설치
cd server
pnpm install
cd ..
```

### **4단계: 환경 변수 설정**
```bash
# 서버 환경 변수 설정
cd server
cp env.example .env

# .env 파일 편집
# MONGODB_URI, JWT_SECRET 등 설정
```

### **5단계: 데이터베이스 샘플 데이터 생성**
```bash
# 서버 디렉토리에서 실행
cd server
node scripts/fix-and-seed-data.js
cd ..
```

### **6단계: 통합 검증 시스템 테스트**
```bash
# 프로젝트 루트에서 실행
check.bat
```

### **7단계: 애플리케이션 실행**
```bash
# 서버 시작 (터미널 1)
cd server
pnpm run dev

# 클라이언트 시작 (터미널 2)
cd client
pnpm run dev
```

```bash

# 프로세스 종료

```
