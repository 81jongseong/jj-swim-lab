# 📱 JJ Swim Lab - PWA 오프라인 가이드

## 🎯 **개요**
JJ Swim Lab은 완전한 Progressive Web App (PWA)으로, 인터넷 연결 없이도 핵심 기능들을 사용할 수 있습니다.

---

## 📱 **PWA 설치 방법**

### **🌐 웹 브라우저에서 설치**
1. **Chrome/Edge**: 주소창 오른쪽 "설치" 버튼 클릭
2. **Safari**: 공유 버튼 → "홈 화면에 추가"
3. **Firefox**: 메뉴 → "홈 화면에 설치"

### **📲 모바일에서 설치**
1. **Android**: Chrome에서 "홈 화면에 추가" 알림 확인
2. **iOS**: Safari에서 공유 버튼 → "홈 화면에 추가"

## 🔄 **동기화 시스템**

### **자동 동기화**
- **온라인 복구 감지**: 네트워크 연결 복구 시 자동 시작
- **순차 업로드**: 오프라인 작업을 시간순으로 서버에 업로드
- **충돌 해결**: 서버 데이터와 충돌 시 지능형 병합

### **수동 동기화**
- **동기화 버튼**: 오프라인 표시기에서 수동 동기화 가능
- **상태 표시**: 동기화 진행 상황 실시간 표시
- **오류 처리**: 동기화 실패 시 재시도 옵션 제공

## 💾 **오프라인 데이터 저장**

### **IndexedDB 저장소**
- **용량**: 브라우저당 최대 수 GB
- **데이터 타입**: 강습법, 학생 정보, 건강 데이터, 퀴즈 등
- **보안**: 브라우저 보안 정책에 따른 안전한 로컬 저장

### **캐시 전략**
- **정적 자산**: CSS, JS, 이미지 → Cache First
- **API 데이터**: 사용자 데이터 → Network First with Offline Fallback
- **페이지**: HTML 페이지 → Stale While Revalidate


### **오프라인 데이터베이스**
```typescript
// IndexedDB 기반 로컬 데이터베이스
export class OfflineDB {
  // 사용자 데이터 저장
  async saveUser(user: User): Promise<void>
  
  // 강습법 데이터 저장
  async saveTeachingMethod(method: TeachingMethod): Promise<void>
  
  // 오프라인 액션 저장
  async saveOfflineAction(action: OfflineAction): Promise<void>
}
```

### **오프라인 감지**
```typescript
// 네트워크 상태 모니터링
export function useOffline() {
  const [isOnline, setIsOnline] = useState(navigator.onLine);
  
  useEffect(() => {
    const handleOnline = () => setIsOnline(true);
    const handleOffline = () => setIsOnline(false);
    
    window.addEventListener('online', handleOnline);
    window.addEventListener('offline', handleOffline);
  }, []);
}
```

## 🔧 **개발자 가이드**

### **오프라인 기능 추가 방법**
1. **데이터 캐싱**: `offlineDB.saveData()` 사용
2. **오프라인 액션**: `offlineDB.saveOfflineAction()` 사용
3. **동기화 로직**: `syncOfflineData()` 함수에 추가
4. **UI 업데이트**: `useOffline` 훅으로 상태 확인

### **테스트 방법**
1. **Chrome DevTools**: Network 탭에서 "Offline" 체크
2. **실제 테스트**: WiFi/모바일 데이터 끄고 테스트
3. **동기화 테스트**: 오프라인에서 작업 후 온라인 복구 확인

## 📊 **성능 및 제한사항**

### **저장 용량**
- **IndexedDB**: 브라우저당 수 GB (충분한 용량)
- **캐시**: 정적 자산 약 50MB
- **로컬 스토리지**: 설정 데이터 약 10MB

### **제한사항**
- **실시간 데이터**: 서버와의 실시간 동기화 불가
- **파일 업로드**: 대용량 파일 업로드는 온라인 필요
- **AI 분석**: 서버 기반 AI 분석은 온라인 필요
