# 🎯 CSS 측정 시스템 완성

## 📊 **CSS란?**

**Critical Swim Speed (임계 수영 속도)**
- 30분 이상 지속 가능한 최고 속도
- 유산소/무산소 역치(MLSS)의 근사값
- 모든 훈련 페이스의 기준

## ✅ **CSS 시스템 개선사항**

### **1. 목표별 최적 CSS 거리**

```typescript
목표: 실력 향상/스피드 → 100m CSS 우선
목표: 체력 향상/기술/재활 → 200m CSS 우선
목표: 장거리/오픈워터 → 400m CSS 우선
```

**이유**:
- 단거리 목표: 짧은 거리 CSS가 무산소 역치 더 정확하게 반영
- 장거리 목표: 긴 거리 CSS가 유산소 역치 더 정확하게 반영

### **2. CSS 우선순위 (자동 선택)**

```
1순위: 목표에 맞는 거리의 실측 CSS
  └─ 장거리 목표 + 400m CSS 있음 → 사용

2순위: 다른 거리 CSS → Riegel 공식 변환
  ├─ 400m → 100m 변환
  ├─ 200m → 100m 변환
  ├─ 50m → 100m 변환
  └─ 25m → 100m 변환

3순위: 레벨별 추정값
  ├─ beginner: 150초/100m
  ├─ intermediate: 120초/100m
  ├─ advanced: 90초/100m
  └─ master: 75초/100m
```

### **3. CSS 기반 페이스 계산 (비율)**

```typescript
Z1 (회복): CSS × 1.18 (+18% 느림)
Z2 (유산소): CSS × 1.09 (+9% 느림)
Z3 (역치): CSS × 1.00 (CSS 기준)
Z4 (VO₂): CSS × 0.91 (-9% 빠름)
Z5 (스프린트): CSS × 0.83 (-17% 빠름)
```

**효과**: CSS 60초든 150초든 정확한 비율로 페이스 계산

### **4. CSS 기반 휴식 시간 (개인별)**

```typescript
baseRest × (memberCSS / 90초)
```

**예시**:
- 빠른 선수 (CSS 70초): Z3 휴식 = 20 × (70/90) = 16초
- 느린 선수 (CSS 120초): Z3 휴식 = 20 × (120/90) = 27초

## 🎯 **CSS 측정 세션 (자동 삽입)**

### **측정 주기** (과학적 권장)

| 레벨 | 기본 주기 | 장거리 목표 | 실력 향상 |
|------|----------|------------|----------|
| 초급 | 4주 | 4주 | 4주 |
| 중급 | 5주 | 5주 | 4주 |
| 상급 | 6주 | 8주 | 4주 |
| 마스터 | 6주 | 8주 | 6주 |

**근거**:
- 초급/중급: 기술 향상이 빠름 → 자주 측정
- 장거리: 유산소 적응이 느림 → 8주 간격
- 실력 향상: 빠른 피드백 → 4주 간격

### **측정 프로토콜** (Wakayoshi 1993)

**상급 이상 (400m + 200m)**:
1. 워밍업 800m @ Z1
2. 400m 전력 수영 (T400 기록)
3. 완전 회복 10-20분
4. 200m 전력 수영 (T200 기록)
5. CSS 계산: (400-200)/(T400-T200) m/s
6. 쿨다운 400m @ Z1

**초급/중급 (200m + 100m)**:
- 부담 감소를 위해 거리 절반

### **자동화 로직**

```typescript
// 주간 프로그램 생성 시 자동 확인
if (weekHistory에 CSS_TEST 없음 || 마지막 측정이 N주 이전) {
  마지막 훈련일을 CSS 측정 세션으로 대체
  테마: 'CSS 측정일'
  이력에 'CSS_TEST' 추가
}
```

### **측정 후 자동 업데이트**

**프론트엔드**:
1. CSS 측정 세션 완료 시 자동 감지
2. T400, T200 입력 UI 표시
3. CSS 자동 계산
4. 회원 프로필 자동 업데이트 API 호출

**백엔드**:
- PUT `/api/users/:userId/swimming-profile/css`
- 업데이트 이력 기록
- 다음 프로그램부터 새 CSS 적용
