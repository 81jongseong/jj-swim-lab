## 🎯 커뮤니티 구조

### 현재 구현된 카테고리 (7개)

#### 1. 💡 **팁 (Tip)**
- **목적**: 수영 관련 노하우 및 꿀팁 공유
- **콘텐츠 예시**:
  - 자유형 호흡법 완전 정복
  - 턴 동작 마스터하기
  - 수영 장비 추천 및 사용법
  - 부위별 근력 강화 운동
- **관리 포인트**:
  - 검증된 정보인지 확인
  - 잘못된 정보는 댓글로 수정 유도
  - 우수 팁은 공지사항으로 승격

#### 2. ❓ **Q&A (Question)**
- **목적**: 수영 관련 질문과 답변
- **콘텐츠 예시**:
  - 접영 킥 동작이 어려워요
  - 물공포증 극복 방법?
  - 초보자 장비 추천 부탁드립니다
- **관리 포인트**:
  - 질문에 답변이 달리지 않으면 강사 멘션
  - 해결된 질문은 "해결됨" 태그 추가
  - FAQ로 만들 수 있는 좋은 질문 큐레이팅

#### 3. ⭐ **후기 (Review)**
- **목적**: 강습 수강 후기 및 경험 공유
- **콘텐츠 예시**:
  - JJ Swim Lab 3개월 수강 후기
  - 00 강사님 강습 추천!
  - 초보에서 중급까지 성장기
- **관리 포인트**:
  - 진정성 있는 후기 장려
  - 과도한 홍보성 후기는 주의
  - 우수 후기는 홍보 자료로 활용

#### 4. ⚡ **번개모임 (Meetup)**
- **목적**: 즉석 수영 모임 주선
- **필수 정보**:
  - 📍 장소 (수영장 이름, 층)
  - ⏰ 날짜/시간
  - 🏊‍♂️ 영법 (자유형, 배영 등)
  - 📏 거리 (1000m, 2000m 등)
  - ⚡ 페이스 (예: 100m당 2분)
  - 👥 최대 인원
  - 💰 비용 (레인비 분할)
  - 🎯 레벨 (초급, 중급, 고급)
- **관리 포인트**:
  - 안전 수칙 공지 (구명조끼, 응급처치)
  - 최소 인원 미달 시 취소 정책
  - 참가자 연락처 교환 유도
  - 노쇼(no-show) 방지 대책

#### 5. 🎉 **이벤트 (Event)**
- **목적**: 대회, 행사, 특별 프로그램 안내
- **콘텐츠 예시**:
  - 2025 JJ Swim Lab 챔피언십
  - 겨울 특별 강습 이벤트
  - 수영 페스티벌 참가자 모집
- **관리 포인트**:
  - 공식 이벤트는 공지사항과 연동
  - 일정/장소/참가비 명확히 기재
  - 마감일 관리

#### 6. 💬 **자유 (General)**
- **목적**: 수영 관련 자유로운 대화
- **콘텐츠 예시**:
  - 오늘 수영하고 왔어요!
  - 수영 관련 영화 추천
  - 수영 다이어트 성공담
- **관리 포인트**:
  - 주제 이탈 방지 (수영 관련성 유지)
  - 긍정적인 분위기 조성
  - 과도한 잡담은 적절히 안내

#### 7. 🏠 **전체 (All)**
- 모든 카테고리 통합 뷰
- 최신순 정렬

## 🛡️ 최고 관리자 관리 기능

### 1. 블라인드 (🚫)

**사용 시기:**
- 욕설, 비방, 차별적 표현
- 개인정보 무단 공유
- 과도한 광고 및 홍보
- 허위 정보 유포

**처리 방법:**
```
1. 게시글의 "🚫 블라인드" 버튼 클릭
2. 확인 메시지
3. 게시글이 일반 사용자에게 숨김 처리
4. 작성자는 여전히 볼 수 있음 (자신의 위반 확인)
5. 🚫 블라인드 배지 표시
```

**효과:**
- 즉시 다른 사용자에게 숨김
- 작성자에게 경각심 제공
- 삭제보다 부드러운 조치

---

### 2. 경고 (⚠️)

**사용 시기:**
- 커뮤니티 규칙 위반
- 반복적인 부적절한 행동
- 타 회원과의 갈등 유발
- 카테고리 무시 (팁에 홍보글 등)

**처리 방법:**
```
1. 게시글의 "⚠️ 경고" 버튼 클릭
2. 경고 사유 입력 (예: "욕설 사용")
3. 작성자에게 경고 메시지 자동 발송
4. 경고 카운트 증가
5. ⚠️ 경고 N회 배지 표시
```

**경고 누적 정책:**
```
1차 경고 → 메시지 발송
2차 경고 → 게시글 자동 블라인드
3차 경고 → 7일 커뮤니티 이용 정지
4차 경고 → 영구 이용 정지
```

---

### 3. 삭제 (🗑️)

**사용 시기:**
- 심각한 규칙 위반
- 불법 정보 유포
- 명백한 스팸
- 법적 문제 소지

**처리 방법:**
```
1. 게시글의 "🗑️ 삭제" 버튼 클릭
2. 확인 메시지
3. 게시글 및 댓글 완전 삭제
4. 복구 불가
```

**주의사항:**
- 신중하게 사용 (복구 불가)
- 가능하면 블라인드 먼저 고려
- 삭제 사유 기록 권장

---

### 4. 운영 규칙 설정 (⚙️)

**기본 규칙 (수정 가능):**
1. 존중과 배려: 모든 회원을 존중하고 예의를 지켜주세요
2. 욕설 및 비방 금지: 욕설, 비방, 차별적 표현은 엄격히 금지됩니다
3. 광고 및 홍보 금지: 무분별한 광고나 영리 목적의 게시물은 삭제됩니다
4. 개인정보 보호: 타인의 개인정보를 무단으로 공유하지 마세요
5. 적절한 카테고리 사용: 게시글은 적절한 카테고리에 작성해주세요

**제재 단계 (수정 가능):**
- 1차 위반: 경고 메시지 발송
- 2차 위반: 게시글 블라인드 처리
- 3차 위반: 7일 커뮤니티 이용 정지
- 4차 이상: 영구 이용 정지

**규칙 수정 방법:**
```
1. "⚙️ 운영 규칙" 버튼 클릭
2. 규칙 및 제재 정책 수정
3. 실시간 미리보기 확인
4. "저장하기"
5. 모든 사용자에게 적용
```

## 💡 성공적인 커뮤니티 운영 팁

### 초기 활성화 (1-3개월)

**1. 시드 콘텐츠 준비**
```
- 강사들이 먼저 팁 게시글 작성 (주 2-3개)
- 센터에서 공식 이벤트 공지
- 우수 회원 후기 유도 (혜택 제공)
```

**2. 참여 유도**
```
- 첫 글 작성자에게 작은 혜택 (포인트 등)
- 주간 베스트 게시글 선정
- 댓글 작성 이벤트
```

**3. 안전한 분위기 조성**
```
- 초기에는 엄격한 모니터링
- 긍정적인 댓글 장려
- 부정적인 글은 즉시 대응
```

---

### 성장기 (3-12개월)

**1. 자발적 참여 촉진**
```
- 월간 우수 회원 선정
- 카테고리별 랭킹 시스템
- 포인트 적립 및 혜택
```

**2. 콘텐츠 다양화**
```
- 주제별 챌린지 (30일 수영 챌린지 등)
- 온라인 토론회
- 수영 관련 설문조사
```

**3. 오프라인 연계**
```
- 번개모임을 공식 프로그램으로 발전
- 우수 회원 초청 행사
- 커뮤니티 회원 전용 할인
```

---

### 성숙기 (12개월 이후)

**1. 자치 시스템 도입**
```
- 우수 회원을 부운영자로 임명
- 카테고리별 관리자 배치
- 신고 시스템 자동화
```

**2. 전문화**
```
- 영법별 전문 커뮤니티 분리
- 레벨별 그룹 (초급/중급/고급)
- 지역별 모임 활성화
```

**3. 외부 확장**
```
- 다른 수영장과 연합 이벤트
- 전국 수영인 네트워킹
- 수영 관련 기업 파트너십
```

