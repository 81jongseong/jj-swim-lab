## 📊 **현재 상태 분석**

### 🛠️ **도구 (Tools) 메뉴**
```
현재 메뉴 구조:
1. ⚙️ 3D 뷰어 관리 (/admin/3d-viewer/management) ❌ 없음
2. 🏊‍♂️ 영법 종류 관리 (/admin/3d-viewer/swimming-styles) ✅ 있음
3. 🎯 드릴 관리 (/admin/3d-viewer/drills) ✅ 있음
4. 📦 3D 모델 관리 (/admin/3d-viewer/models) ❌ 없음
5. 🧪 기본 3D 뷰어 (/3d-viewer) ✅ 있음 (빈 껍데기)
6. 🚀 고급 3D 뷰어 (/3d-viewer/advanced) ✅ 있음 (빈 껍데기)
```

**문제점:**
```
❌ 기본 vs 고급 3D 뷰어 차이 불명확
   - 기본: 빈 UI만 있음 (Three.js 컴포넌트 없음)
   - 고급: 설정만 있고 실제 3D 렌더링 없음
   
❌ 3D 뷰어 관리 페이지 없음
   - /admin/3d-viewer/management 404
   
❌ 3D 모델 관리 페이지 없음
   - /admin/3d-viewer/models 404
   
❌ 드릴 관리 중복
   - 수영 엔진의 드릴 관리 (실제 DB 연동)
   - 3D 뷰어의 드릴 관리 (하드코딩)
```

### 🎯 **체험 (Experience) 메뉴**
```
현재 메뉴 구조:
1. 🧠 퀴즈 (/quiz) ✅ 작동
2. 🎬 애니메이션 (/(labs)/animation) ❌ 없음
```

**상태:**
```

- 🤖 AI 분석 (/ai-analysis) ✅ 작동

목적: 강사/센터관리자가 학생 AI 분석 제공
권한: instructor, centerAdmin만 접근 가능
```

**문제:**
```
❌ AI 시스템 메뉴는 제거했는데 체험에는 남아있음
❌ Guest가 접근 불가능한데 "체험"이라고 함
❌ 실제로는 강사용 도구임
```

## ✅ **통합 전략**

### 1️⃣ **3D 뷰어 메뉴 재구성**

#### 현재 문제:
- 기본 vs 고급 차이 불명확
- 없는 페이지들 링크
- 실제 3D 렌더링 기능 없음

#### 해결책:
```
Option A: 하나로 통합
✅ 🏊‍♂️ 3D 수영 뷰어 (/3d-viewer)
   - 설정 옵션 포함
   - 실제 3D 렌더링 구현
   - 영법/드릴 시각화

Option B: 관리자 전용으로 정리
✅ 🏊‍♂️ 영법 종류 관리 (유지)
✅ 🎯 드릴 관리 (유지, 하지만 수영 엔진과 통합 필요)
❌ 나머지 제거

🎯 추천: Option A + B 혼합
- 일반 사용자: /3d-viewer (통합된 하나)
- 관리자: 영법/드릴 관리 (DB 기반)
```

### 2️⃣ **체험 메뉴 정리**

#### 현재:
```
✅ 퀴즈 (작동)
❌ 애니메이션 (없음)
```

#### 해결책:
```
Option A: 애니메이션 페이지 제거
✅ 퀴즈만 유지

Option B: 애니메이션 페이지 생성
✅ 간단한 수영 애니메이션 데모 추가
   (CSS 또는 Lottie 사용)

🎯 추천: Option A (없는 건 삭제)
```

### 3️⃣ **AI 분석 재배치**

#### 현재 문제:
```
❌ Guest 메뉴에 "AI 체험"이라고 있지만
   실제로는 강사/센터관리자만 접근 가능
❌ "체험"이 아니라 실제 업무 도구임
```

#### 해결책:
```
Option A: AI 분석을 강사 전용 메뉴로 이동
✅ instructor, centerAdmin 메뉴에만 표시
   - 🤖 AI 학생 분석
   
Option B: Guest용 AI 데모 페이지 별도 생성
✅ /ai-demo (비회원 체험용)
   - 샘플 동영상 분석
   - 제한된 기능 데모
   
Option C: 완전 제거
❌ AI 분석 자체를 삭제

🎯 추천: Option A
- 체험 메뉴에서 제거
- 강사 메뉴로 이동
```
