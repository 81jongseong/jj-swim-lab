# 🏊‍♂️ JJ Swim Lab - 개인 PT & 단체반 통합 시스템 완성

**✅ 완성일: 2025-01-09**

## 📋 **핵심 개념**

### **개인 PT vs 단체반**

| 구분 | 개인 PT | 단체반 |
|------|---------|--------|
| **대상** | 1:1 맞춤 레슨 | 그룹 레슨 (초급반, 중급반, 상급반) |
| **프로그램** | 완전 개인화 | 공통 프로그램 + 개인별 조정사항 |
| **표시** | 🏊 이름 (개인) | 📚 반 이름 (N명) |
| **생성** | 개별 생성 | 1개 생성 → 전체 배포 |
| **조정** | 생성 시 반영 | 조회 시 실시간 계산 |

```typescript

  athleteId: userId,
  programScope: 'individual'
});

// 단체반 프로그램
const groupPrograms = await SwimProgram.find({
  groupClassId: { $in: myGroupClassIds },
  programScope: 'group'
});

// 통합 반환
return [...individualPrograms, ...groupPrograms];
```
