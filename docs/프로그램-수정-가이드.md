# 🏊 프로그램 세부 수정 가이드

## 🎯 **3단계 수정 시스템**

### **Level 1: 기본 파라미터 수정**
```
용도: 시작일, 총 거리, CSS, 영법 변경

예시:
- 시작일: 다음 주로 연기
- 거리: 8000m → 10000m (강도 증가)
- CSS: 100초 → 95초 (실력 향상)
- 영법: 자유형 → 배영
```

### **Level 2: 요일별 세션 수정**
```
용도: 특정 요일의 전체 세트 관리

예시:
- 월요일만 수정
- 세트 추가/삭제
- 전체 재구성
```

### **Level 3: 개별 세트 상세 수정** ⭐
```
용도: 페이스, 휴식시간, 거리 등 미세 조정

예시:
"8×100m 지구력 빌드 @~1:40 per 100m, r 20″"
    ↓ 수정
"10×100m 지구력 빌드 @~1:35 per 100m, r 30″"

변경 사항:
✅ 반복: 8 → 10
✅ 페이스: 1:40 → 1:35 (더 빠르게)
✅ 휴식: 20″ → 30″ (더 충분히)
```

## 📝 **수정 워크플로우**

### **시나리오: 월요일 메인 세트 페이스 조정**

```
프로그램 목록 탭
  ↓

  ↓

```

```

  • 😌 Cool-down (160m)

```

  • 휴식시간: r 20″ → r 30″

## 🔍 **수정 가능한 항목 상세**

### **1. 반복 횟수 (Reps)**
```
예시: 8×100m → 10×100m

영향:
- 총 거리: 800m → 1000m
- 피로도: 증가
- 세션 시간: +5분
```

### **2. 페이스 (Pace)**
```
예시: @~1:40 → @~1:35

의미:
- 100m당 1분 40초 → 1분 35초
- 강도: 증가
- 더 빠른 타임
```

### **3. 휴식시간 (Rest)**
```
예시: r 20″ → r 30″

의미:
- 20초 휴식 → 30초 휴식
- 회복: 증가
- 품질: 향상
```

### **4. 거리 (Distance)**
```
예시: 100m → 150m

영향:
- 반복당 거리 증가
- 지구력 요구 증가
- 총 거리 변경
```

### **5. 강도 Zone**
```
예시: Z3 → Z4

의미:
- Z3 (Threshold) → Z4 (VO2max)
- 강도: 증가
- 페이스: 더 빠름
```

### **6. SPL (Strokes Per Length)**
```
예시: SPL≈36 → SPL≈34

의미:
- 스트로크 수 감소
- 효율성 증가
- 글라이드 증가
```

### **7. Tempo**
```
예시: Tempo≈1.05s/st → Tempo≈0.95s/st

의미:
- 스트로크 속도 증가
- 리듬 빨라짐
- 파워 증가
```

## 🚀 **실제 사용 예시**

### **케이스 1: 선수 실력 향상**
```
상황: 김민수가 CSS 100→95초로 향상

수정:
1. 프로그램 목록 → 김민수 카드 클릭
2. [✏️ 수정] 클릭
3. CSS: 100 → 95
4. [💾 저장]

결과:
✅ 모든 페이스 자동 조정
✅ SPL/Tempo 재계산
✅ 강도 적정 유지
```

### **케이스 2: 특정 요일 강도 조절**
```
상황: 수요일이 너무 힘듦

수정:
1. 프로그램 상세 → 수요일 [✏️ 수정]
2. 메인 세트 클릭
3. 텍스트 수정:
   "12×75m @~1:10, r 60″"
   → "8×75m @~1:15, r 90″"
4. [💾 저장]

결과:
✅ 반복: 12 → 8 (볼륨 ↓)
✅ 페이스: 1:10 → 1:15 (강도 ↓)
✅ 휴식: 60″ → 90″ (회복 ↑)
```

### **케이스 3: 세트 추가**
```
상황: 금요일에 특수 드릴 추가

수정:
1. 금요일 [✏️ 수정]
2. [➕ 세트 추가] 클릭
3. 새 세트 클릭하여 수정:
   "4×50m 캐치업 드릴 @~0:55, r 45″"
4. [💾 저장]

결과:
✅ 금요일에 드릴 세트 추가됨
✅ 총 거리 자동 업데이트
```
